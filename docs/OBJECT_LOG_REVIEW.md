## 两个最能定位错误的对照

最新复查继续追踪共享 M1a+D2 的十人 R80。完整词表成图前命中为 28.5/2,000，真图相对 token 的 32、128、512 维干预在同一开发面板分别命中 60、87、98/200。纯视觉流、跨照目标和全头皮对照的实测还没有带来稳定的主体成图提升。 [逐轮实验与实际成图](../research/eeg_stack_20261112/TOKEN_GATE_ZERO_STUDY.md)

1. **顺着同一条 EEG 看图像条件到成图的损失。** 十人官方 R80，逐人 D2 在扩散前有 748 条从 200 个视觉向量中精确找回原照。这 748 条里，生成图再次精确找回原照的有 116，物体命名只得 17 分。完整 1,654 训练类的 Brain‑HiVE 也是 961 条特征找对、176 条图片找对、33.5 分命名。每一行都核对了照片标识和实际检查点。真图排第一只需要略微领先竞争图片，生成器却必须从该条件本身读出足够清楚的物体身份。[逐查询衔接](../research/eeg_stack_20261112/code/paper_error_readout.py) · [命中与未命中组](PAPER_BENCHMARK_RESULTS.md)
2. **固定生成器，只换条件。** 空提示、四步、200 张开发照片。给真实照片的冻结视觉条件，成图命名为 105/200；给训练集平均视觉条件，命名为 0/200。原图自身在同一命名器下为 164/200。EEG 到视觉条件有很大改进空间，哪怕给真实条件，生成和自动命名仍会丢掉一部分目标。[生成接口干预](../research/eeg_stack_20261112/code/paper_image_calibration.py) · [同图库实测](PAPER_BENCHMARK_RESULTS.md)

## 拟合的注意力更新中有多少来自当前 EEG

对十人完整开发面板的 2,000 条查询，逐被试、逐图像 token 槽位求新增键和值投影的均值。共享能量比例为各层均值投影的平方和，除以各层完整投影的平均平方和。训练均值由每位被试的 13,230 张注册训练照片独立计算。最后一列报告输入减去训练均值后，原已训练投影剩余的能量比例。

| 训练目标 | 开发集共享投影能量 | 减去训练均值后的投影能量 |
| --- | ---: | ---: |
| 照片监督 | 99.6500% | 0.3624% |
| 照片与主体监督 | 99.7133% | 0.2956% |
| 梯度约束 | 99.7284% | 0.2805% |

旧分支已训练的键和值投影，大部分能量在同一被试的查询之间共享。这个估计给出了错配实验中分数变化很小的一个可测解释。下一轮用训练集的均值和均方根归一化新增分支，每次去噪仍保留原有 EEG 条件。配对训练在固定同一布局和噪声下比较当前 EEG 与错配 EEG 的新增作用。12 次更新的预检覆盖十位被试和两种配对，零初始化与冻结生成完全一致，12 次都有可用梯度。主体与原照分数由完整十人开发评估测定。测量、校准和预检作业分别为 `5400086`、`5400152` 和 `5400166`。
