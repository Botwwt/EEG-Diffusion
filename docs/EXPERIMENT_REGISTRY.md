## How the selected model was built

1. **Train the EEG backbone.** Arm0 fits the shared O13-style encoder on concepts from folds 1–4 using EEG from all ten participants. Arm1 adds within-concept representation supervision. SwapDiff Arm3b continues from Arm1, learning to distinguish correctly paired EEG and photographs from swapped pairs through a frozen denoising U-Net and a learned residual on four image-conditioning tokens. [Backbone training](../research/eeg_stack_20261112/code/exp0_intra10_swap_gate.py) · [Arm3b training](../research/eeg_stack_20261112/code/exp3_swapdiff_v3.py)
2. **Train the conditioning layer through four generator steps.** D2 starts from Arm3b, freezes its EEG encoder and trains the conditioning layer with four competing photographs of the same concept. D1 provides the similarity-only control. [D2 executor](../research/eeg_stack_20261112/code/exp6_draft_intra4.py) · [DRaFT ablations](../research/eeg_stack_20261112/DRAFT_INTRA4_REPORT.md)
3. **Apply M1a and reconstruct.** For each group of four EEG trials, weight each channel by inverse trial RMS before encoding. Mix that feature (72%) with the mean of the four separately encoded trial features (28%). A participant-specific ridge regression fitted on the training folds predicts the starting latent from the weighted EEG. At s375 the runner uses an anchoring coefficient of 0.375, four U-Net evaluations and one candidate per image. [EEG weighting and ridge fit](../research/eeg_stack_20261112/code/exp8_trial_precision_swapdiff.py) · [Selected-model executor](../research/eeg_stack_20261112/code/exp8c_m1a_heldout6_confirm.py)

## Protocols and evidence

Two implementation details affect comparisons. The ordinary starting-latent ridge uses 768 PCA directions. The M1a starting-latent ridge uses 256 with a subject-dependent PCA seed, and rescales predictions using the participant's evaluation-batch EEG predictions. A naive-versus-M1a generation difference therefore combines several changes. Comparing two M1a arms holds this starting-latent path fixed. [Ordinary ridge](../research/eeg_stack_20261112/code/exp0_intra10_swap_gate.py) · [M1a ridge](../research/eeg_stack_20261112/code/exp8_trial_precision_swapdiff.py)

The EEG training and evaluation photos are separated by concept in the published R4 executors. The default semantic-target recipe samples nuisance VAE features across the original training pool, and the B32 conversion also calibrates on that broader visual pool. Both may include images later assigned to fold 0. Exact cache provenance matters for a claim of fully unseen visual concepts. A prospective confirmation should fit both transformations within the training folds. [Semantic-target construction](../research/eeg_stack_20261112/code/o10_factorized.py) · [B32 calibration](../research/eeg_stack_20261112/code/b32fix.py)

## Availability

The follow-up [signed local prediction error study](CONTEXT_RESIDUAL.md) used an older sub-03 mean-of-four EEG archive. It covers two VAE retrieval experiments and a four-arm, 800-image generation comparison. Its strongest generation arm identified 28 of 200 photographs against 27 for direct prediction. The ten-participant R4 selection above uses a different checkpoint and stimulus panel.

The release contains source, participant summaries and selected images. GPU replay requires separately obtained THINGS-EEG2 trials and stimuli, prepared EEG/visual caches, Brain-HIVE and SDXL-Turbo assets, evaluator weights and the trained Arm3b and D2 states. The selected evaluator loads `arm3b_rep_rawswap_condlyr_st600_s2025.pt` and `d2_compete4_cond_st120_s2025.pt` from the research workspace. The public Git tree contains neither checkpoint.
