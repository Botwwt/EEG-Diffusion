# O13 确认实验设计存档

以下是 11 月 22 日为 R80 研究线设计的方案。11 月 24 日收敛后的 R4 主模型、对照与新实验分别见[模型与证据](CURRENT_RESEARCH.md)和[局部残差先导实验](CONTEXT_RESIDUAL.md)。

更新于 2026-11-22。现有数值、创新边界与资料入口见[当前结果与投稿评估](CURRENT_RESEARCH.md)。

## 1. 确认同刺激配对能否保留同类实例

先问一个问题。每张图只有四次 EEG 记录时，真实同刺激的跨被试配对，能否提高生成图对同一物体概念下不同照片的辨识？O13 单独分支相对共享训练对照已有正向线索。CHORUS 也在固定扩散生成器上报告了跨被试重建，因此应同时比较它采用的同图像跨人平均策略。[CHORUS 生成实验](https://arxiv.org/html/2611.24364#S4.SS6)

### 先封存数据划分和共用输入

从 THINGS-EEG2 原训练分区按物体概念划分训练、开发和复验。同概念的十张照片以及它们在所有被试中的记录划入同一分区。复验概念优先选择未用于此前开发打分的概念。按新训练折重新拟合白化和统计量、视觉条件及起始图读出。归档 O13 单独分支也读取 O10 的起始潜变量，复验使用来自新训练折的共用起始图，例如固定的 EEG→VAE ridge 读出。训练过的被试可用于本轮评价，研究范围为同一批被试对新概念的表现。[THINGS-EEG2 数据协议](https://pmc.ncbi.nlm.nih.gov/articles/PMC9771828/) · [O13 条件导出](../research/eeg_stack_20261112/code/o13_xbrain_shared_trunk.py)

归档脚本按 200 个刺激、每刺激 80 次试次导出条件。首个代码改动是让复验入口显式读取划分清单、刺激 ID 和试次数。用小批开发数据检查同概念错配、重复号对齐及评分进程与生成输入的隔离。

### 先在开发集跑通，再验证固定方案

| 实验组 | 训练处理 |
| --- | --- |
| 共享训练基线 | 使用相同训练被试、样本和视觉目标，`λ_x=0` |
| 真实同刺激配对 | 使用归档 O13 的 EEG–EEG 对比项，`λ_x=0.25` |
| 同概念错配 | 把另一人的正配对换为同概念的另一张照片，保留两路 EEG 各自的正确视觉监督 |
| 同刺激平均基线 | 以相同原始 EEG 观测量和更新步数比较同图像跨人平均训练 |

先用一个训练种子在开发集验证四组的试次对齐、配对和出图评分。复验前冻结多个训练种子、同一四步生成设置和成对生成噪声。主指标用 R4 逐查询生成图的同概念 10 选 1，随机为 10%。分开报告 EEG 表征检索、生成图 CLIP 200 选 1 和独立图像评价器的结果。R1、R2 为重复数敏感性分析。把每个被试和刺激的生成结果先对种子取平均，再据配对差报告效应量与考虑被试和概念聚类的区间。官方 R80 继续作为历史基准参考。

主结果使用训练折统计、逐查询推理和固定权重。若复查测试时适配，先从另一个划分拟合再冻结应用。只有在真实配对相对共享基线、同概念错配和同图像平均的增量得到支持时，才推进以实例级辨识为主张的方法稿。若优势停在表征检索，定位生成阶段的信息损失。若区间仍宽，报告不确定性，再根据效应量决定是否增加独立数据。

## 2. 建立外部可比性

以 Brain-HIVE 和 ENIGMA 或 ATM 的可运行实现作对照。记录数据版本、通道、重复数、模型是否训练过测试被试、适配是否使用最终测试批、每次候选数和 U-Net 次数。统一后处理、评分方向、候选库和生成种子。若论文主张是更高的人类可辨识性，增加盲法人工识别。若主张包含提速，记录同硬件的端到端时延、显存和训练成本。

## 3. 使主表可以复跑

锁定环境与外部模型版本，给出生成缓存的来源和校验值，以及评估脚本、刺激顺序、训练种子、逐被试 × 刺激 × 生成种子的排名与主表重算命令。遵照上游许可注明需要自行获取的资产。确认实验完成后再决定完整方法稿的主张强度。
