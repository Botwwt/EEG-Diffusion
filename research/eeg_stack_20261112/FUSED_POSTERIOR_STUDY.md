# 用实测 EEG 和照片先验修正整图条件

只给生成器正确的整图融合特征时，官方 200 张图有 118.75 个主体命名积分。已有的 EEG 前向模型用两半重复之间的噪声估计提高了成图前的物体判别，一次线性修正的 R4 成图仍与基线持平。这轮让实测 EEG 约束整图特征的每次修正，并比较训练照片学出的去噪器和同预算的简单先验。[整图诊断和一次前向修正](CROSSFIT_GENERATOR_STUDY.md)

## 整图条件的推断

把训练照片的 1,024 维冻结融合特征写到完整的 PCA 坐标。每个方向按其训练标准差缩放，可逆变换保留全部 1,024 维。视觉去噪器只使用注册训练照片。给真条件 $x$ 加上尺度为 $\sigma$ 的独立高斯噪声，拟合 $D_\sigma(x+\sigma\epsilon)\approx x$。每个去噪器训练 2,000 步，每步 192 张。四个整类留出校准版各排除相应训练折，成图版用全部 13,230 张注册训练照片。[照片先验实现](code/paper_fused_prior.py)

用训练照片拟合从该条件到 EEG 的线性映射 $B$。每条 EEG 先在 17 导 0–800 ms 上按 20 ms 分箱，取四次物理呈现的均值。用两组各两次的呈现均值之差估计正则化噪声协方差，对观测和映射同时白化。记白化且校正截距后的观测为 $y$，原生 Brain-HiVE 的坐标为 $x_N$。从 $x_0=x_N$ 出发，依次对噪声尺度 $\sigma=(1,.7,.5,.35,.25,.15)$ 计算

$$
\begin{aligned}
a_k &= .35 x_N+.65 D_{\sigma_k}(x_k), \\
x_{k+1}
&= \arg\min_x \left\{\|x-a_k\|_2^2+\lambda\|Bx-y\|_2^2\right\} \\
&= (I+\lambda B^\top B)^{-1}(a_k+\lambda B^\top y).
\end{aligned}
$$

原生条件和实测一致性项都来自同一段 EEG，这里的求解用于正则修正。同一白化协方差来自该被试的注册训练段。最终回到整图特征空间，并把更新上限设为原生条件离训练中心距离的 85%。对照使用恒等映射、解析高斯去噪 $D_\sigma(x)=x/(1+\sigma^2)$、令 $\lambda=0$ 的学习去噪，以及只交换一致性项的 EEG。所有真实 EEG 版本共享空提示、逐图种子、一次图像生成和四次 U-Net 调用。该类先验与观测交替求解已有逆问题先例，本轮检验的是它用于冻结 EEG 成图条件的表现。[PnP 深度去噪先验](https://github.com/cszn/DPIR) · [联合推断实现](code/paper_fused_posterior.py)

## 整类留出的校准

四位开发被试、四个整类留出折共 52,920 条 EEG。每折的 EEG 前向映射、照片先验和融合到 DINOv2 的读出排除该折。原生条件由没有见过对应物体的 EEG 模型给出。评分选择 DINOv2 物体原型，正类原型排除当前照片。按照学习先验的命中选定一致性强度 3.0，然后对所有真实 EEG 成图组锁定同一强度。

| 训练侧整类留出 | 物体判别 / 52,920 | 与真条件的中心化余弦 |
| --- | ---: | ---: |
| 原生 EEG 条件 | 1,919 | .12238 |
| 仅学习照片先验 | 1,898 | .12210 |
| EEG 一致性，恒等先验 | 2,024 | .12906 |
| EEG 一致性，高斯先验 | 2,117 | .13696 |
| EEG 一致性，学习先验 | 2,122 | .13683 |

四折分别给留出的真照片坐标加入同一分布的高斯噪声。噪声标准差 .7 时，学习先验的四折均方误差均略高于解析高斯先验。这些结果衡量成图前的条件。正式成图只用第 05 和 08 名被试的独立 EEG，每人 200 个官方刺激。

## 真照片方向诊断

训练集每个物体的十张照片分为两半。各半分别计算物体均值，两半均值的对称交叉协方差衡量在不同照片上稳定出现的物体差异。类内的照片离均差用于估计变化协方差。按后者白化并分解物体信号，取 128 个广义特征方向并正交化为 $Q$。对照使用整图特征能量最大的 128 个 PCA 方向。

在第 05 位被试的官方样本上，原生条件记为 $g$。诊断用同一真照片融合向量 $v$，计算方向修正 $(v-g)QQ^\top$。同预算对照分别用该真图沿普通 PCA 方向的修正、另一物体的照片沿 $Q$ 方向的修正。三组每张图使用相同的改动范数，取三个候选各自范数的最小值。诊断使用了测试照片的融合向量，衡量指定方向的传递能力。真实 EEG 成图与此诊断分开运行。[真图方向诊断实现](code/paper_fused_identity_diagnostic.py)

| 参考照片诊断，均为 200 张 | 主体命名积分 | 找回原照 | SSIM |
| --- | ---: | ---: | ---: |
| 正确照片，128 个物体方向 | 37 | 97 | .32072 |
| 正确照片，128 个 PCA 方向 | 52 | 116 | .34881 |
| 另一物体照片，128 个物体方向 | 0 | 2 | .31561 |

三个对照采用相同修正幅度，平均为整条真图修正向量长度的 44.3%。PCA 对物体方向的命名差为 +7.50 个百分点，95% 刺激配对区间 [+1.00, +14.00]。航母与老鹰在固定样例中能被辨认。选出的稳定物体方向对主体有效，等维且等幅度的普通 PCA 方向传递了更多有用信息。这个观察来自一名被试和真图输入。

随后重新用四个整类留出折检验这两套方向。先根据两半重复估计实测噪声，再从当前四次 EEG 用岭回归直接预测 128 个方向。将预测向原生条件混合。另在 PCA 方向内限制 EEG 一致性更新，从 .003 到 10 比较八个强度。四人 52,920 条查询中，原生条件有 1,919 次物体判别，物体方向岭回归的最佳配置有 1,912，PCA 岭回归最佳为 1,833，限制在 PCA 方向内的一致性更新最佳为 1,889。真图能提供的方向收益，仍需要更有效的 EEG 读出才能用于真实成图。[实测方向读出](code/paper_fused_direction_probe.py)

共核对 3,000 张生成图。按主体命名优先的条件，联合推断保留为研究实验。[逐组数值、配对区间和回执](results/fused_posterior.json)

## 复跑

沿用正式基准环境。令 `EEG_CROSSFIT_ROOT` 指向输出目录，`EEG_RUNS_ROOT` 指向当前被试的原生模型目录。在符合规定的计算节点执行。

```bash
python paper_fused_prior.py
python paper_fused_posterior.py calibrate --source-root "$EXISTING_CROSSFIT_RUN"
python paper_fused_posterior.py render 5
python paper_fused_posterior.py render 8
python paper_fused_identity_diagnostic.py 5
```

前两个命令读取注册训练数据。参考照片与名称由独立评分读取，诊断入口有单独的结果目录和标记。第 08 名被试运行前切换其个体权重目录。

```bash
python paper_fused_direction_probe.py --prep "$RAD_ROOT/data/prep" \
  --eeg-root "$RAD_ROOT/data/prep" --photos "$RAD_ROOT/data/prep/F_train.npy" \
  --source-root "$EXISTING_CROSSFIT_RUN" --output "$EEG_CROSSFIT_ROOT/direction-probe.json"
```
