# 将 EEG 的局部照片信息送到对应的空间注意力

真实四次 EEG 中包含一部分同物体照片之间的差异。把真照片的轮廓交给生成器可以改善轮廓，开发组实验的主体命中没有增加。另一组实验表明，Brain-HiVE 的四个图像 token 之间的差异能影响生成主体。这里把照片的局部外观作为视觉目标，并在生成时将每个局部条件送到画面对应的位置。[轮廓对照](OUTLINE_ROUTING_STUDY.md) · [图像 token 交换](TOKEN_EVIDENCE_STUDY.md)

RPA 已把图像 patch 用于 EEG 和 MEG 检索。IP-Adapter 的掩膜接口支持给不同参考图分配生成区域。本轮检验的是从同一段 EEG 读出四组局部图像条件，再检验位置交换会怎样改变最终成图。[RPA](https://arxiv.org/abs/2609.31698) · [IP-Adapter 的区域条件](https://huggingface.co/docs/diffusers/main/en/using-diffusers/ip_adapter)

## 局部目标和生成条件

把每张 500 × 500 注册训练照片取成四个 350 × 350 的重叠裁剪，分别沿左上、右上、左下、右下对齐。令 $I_{ij}$ 为照片 $I_i$ 在第 $j$ 个位置的裁剪。对 H14 和 B32 视觉分支 $b$，将裁剪相对重编码整图的变化加到发布的原始整图嵌入 $v_{ib}$。

$$
v_{ijb} = v_{ib} + E_b(I_{ij}) - E_b(I_i).
$$

B32 用正式训练分割拟合的坐标变换。四个位置共享该照片原始 VAE 分支，然后使用 Brain-HiVE 冻结的视觉融合器将三路特征合成局部目标。直接拿单路 H14 向量与融合表征比较时，参考回放校验未通过。最终实验经三路融合后重放整图，并在每批检查与已注册整图条件的余弦相似度。

令 $G_i$ 是注册整图融合特征，$V_{ij}$ 是局部融合特征，$N(v)=32v/\|v\|_2$。训练目标为 $D_{ij}=N(V_{ij})-N(G_i)$。特征 $x_i$ 由原生 EEG 编码器的输出和同四次 EEG 的分窗均值组成。每位被试使用 13,230 张注册训练照片拟合独立的岭回归，预测局部目标与其全训练均值的差。推理时只对当前查询的四次物理 EEG 计算

$$
\widehat V_j=N\bigl(N(g(e))+\overline D_j+W_j x(e)\bigr),
$$

其中 $g(e)$ 为原生 EEG 的整图条件，$x(e)$ 使用训练集的组分中心和尺度。岭回归的正则为特征协方差平均对角值的 0.5 倍。四个 $\widehat V_j$ 分别通过原生融合适配器和投影，成为四组局部图像 token。

设 $A(q,T)$ 是原生图像注意力对空间位置查询 $q$ 和 token 组 $T$ 的输出。保留整图 EEG 的 token 组 $T_g$，在前两次 U-Net 前向以内，将图像注意力输出调整为

$$
A(q,T_g)+0.65\sum_{j=1}^4 w_j(q)\left[A(q,T_j)-A(q,T_g)\right].
$$

$w_j(q)$ 随画面位置双线性变化，四个权重之和为 1。每个查询仍只生成一张图，执行四次 U-Net 前向。局部组在前两次前向增加四组局部注意力和一个全图注意力计算。所有组共用同一套 U-Net 权重、空提示、逐刺激种子和噪声初始化。[成图与注意力实现](code/paper_spatial_photo.py)

## 对照

真实 EEG 使用第 05 和 08 名被试，各 200 张未参与拟合的官方照片。每条查询用同一位被试的前四次物理呈现。均匀混合让每个位置接收相同的四组局部条件。旋转对照将局部 token 顺序旋转 180 度。错配对照只交换额外的局部预测偏移，整图 EEG 和种子沿用当前查询。训练均值组给局部条件固定的位置偏移。所有真实 EEG 条件的拟合及成图入口与参考照片诊断分开。

第 05 名被试另做参考照片诊断。诊断为相同的原生 EEG 整图条件提供真实局部视觉向量，分别保留位置、均匀混合、旋转位置或交换成另一物体的裁剪。参考照片结果衡量生成器能否利用局部证据。[数据与成图注册](PAPER_BENCHMARK_PROTOCOL.md) · [空间目标准备](code/paper_spatial_photo_targets.py)

## 复跑

沿用正式基准环境。将分组结果写入 `EEG_CROSSFIT_ROOT`，个体权重目录指向当前被试。参考诊断目录的 `test_visual_embeddings.pt` 来自正式视觉参考回执。下面的命令在计算节点运行。

```bash
python paper_spatial_photo_targets.py train --root "$EEG_CROSSFIT_ROOT" --archive "$TRAIN_IMAGES_ZIP"
python paper_spatial_photo.py fit 5
python paper_spatial_photo.py eeg 5
python paper_spatial_photo_targets.py oracle --root "$EEG_CROSSFIT_ROOT" --archive "$TEST_IMAGES_ZIP"
python paper_spatial_photo.py oracle 5
python paper_spatial_photo.py probe 5
```

第 08 名被试重复 `fit`、`eeg` 和 `probe`。评分时读取 1,854 个物体名称和参考照片。主指标为开放物体命名，同时保留整图库原照匹配和 SSIM。
