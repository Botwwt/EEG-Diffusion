## 选型

原照 Top‑1 较高的子集仍缺少可靠的成图前开放词汇主体识别。后续优先在冻结的原照分支旁检验跨照片主体读出，并用实际生成对照度量语义能量是否增加正确物体。纯视觉先验保留单因素分支，使用与原照相似度同坐标系的 1,024 维融合空间，避免在 8,192 维 token 上另行估计从 token 回到融合特征的逆映射。最后通过真实冻结投影进入生成器。源空间优化和严格的 token 密度最大化是不同的目标，后者还含变量变换的雅可比行列式。[D-Flow](https://proceedings.mlr.press/v235/ben-hamu24a.html) · [Brain-HiVE](https://arxiv.org/abs/2602.07495)

作业 `5378485` 的两项输出均已完成。工作数据归档在 `token-rank-check`，其中 `fused-r80/official-r80-fused.json`、`naming-official-r80.json`、`rank-verified.json`、`rank-siglip2.json` 和 `rank-fixed-panel.png` 分别记录重放、命名、成图核验、独立评分和固定样图。上述真图条件只用于机制诊断，正式基准继续使用十名被试的完整 EEG-only R80 任务。

## 视觉流的单因素试验

只用登记的 13,230 张自然图像的 1,024 维原生融合特征训练无条件流匹配。训练没有读取 EEG 或类名。先对全部 1,024 维做带下限的特征值标准化，然后拟合从高斯噪声到图像特征的速度场。令 `v(z)` 表示六步 Euler 解回到原融合空间的向量。冻结 D2 的成图前向量为 `q(x)`。从四个固定高斯初值各优化二十步，只在初始半径对应的球面上最大化 `cos(q(x), v(z))`。每次只保留一个源向量。高斯对照用相同均值、协方差、源初值和优化器，速度场取零。错配只交换不同概念的 EEG 得出的条件。源寻优不接收图库、词表或测试照片。 [流训练与源优化](code/paper_clean_image_flow.py) · [配对成图](code/paper_render_clean_image_flow.py)

### 直接在全部 8,192 个 token 坐标寻优

用同一批 13,230 张登记训练图，经冻结的 Brain‑HiVE 图像投影产生四个 2,048 维 token。保留全部坐标。用训练图的带正则协方差做 Cholesky 白化，得到 $u=L^{-1}(T-\mu)$，再用训练图拟合从 $u$ 到原 1,024 维融合特征的仿射读出 $Wu+b$。在 200 张整类留出真图上，反读向量和原融合向量的平均余弦为 .99760，原图库首位为 200/200。两种源模型共用坐标系、反读映射、四个固定高斯起点和 20 次 Adam 更新。高斯模型使用恒等变换。视觉流用 30 轮无条件流匹配拟合速度场，寻优时用六步 Euler 计算 $F(z)$。

$$
z^\star=\operatorname*{arg\,max}_{\|z\|=r_j}
\cos\big(q(x), W F(z)+b\big),\qquad T^\star=\mu+L F(z^\star).
$$

每个起点保留自己的半径，四个输出里取当前 EEG 能量最大的一组 token。每条 EEG 生成一张图。成图端四步共用该组条件，各臂加回同一条当前 EEG 的原生 D2 残差。高斯和流的差异来自学习到的速度场。错配控制仅替换流条件的 EEG 来源。 [估计与寻优](code/paper_full_token_source_probe.py) · [配对成图](code/paper_render_full_token_source_probe.py)

## 源空间目标与后续实现

设 $T=\mathcal F(z)$ 且 $\mathcal F$ 为等维可逆映射。源变量标准高斯的密度和图像 token 的密度满足

$$
\log p_T(\mathcal F(z)) = -\tfrac12\|z\|^2-\log|\det D\mathcal F(z)|+C.
$$

源空间寻优可以用于生成控制。以 token 密度为目标时要计入体积变化。标准高斯的最高密度在原点，典型样本的范数接近维数的平方根。单独惩罚范数倾向原点。固定源半径可以消除各方案的范数差异，检验同一半径上的寻优。全维高斯经等维微分同胚得到同维分布，训练拟合与源半径约束均无法保证每个寻优输出符合冻结生成器的有效条件。这里已经测了两种接口。完整的 1,024 维融合空间流经真实冻结投影产生 8,192 个 token 坐标，另一组直接在 8,192 个坐标拟合和寻优。两组都只用已登记训练照片拟合视觉先验。外部大图量与图文联合流仍属于待测配置。 [全维流的匹配高斯、错配和投影几何对照](#直接在全部-8192-个-token-坐标寻优)

若对比负例按构图抽样，记抽样密度为 $q_{-}(T\mid x)$。在无限数据和可实现打分器理想条件下，最优分类 logit 为 $\log p_{+}(T\mid x)-\log q_{-}(T\mid x)+C(x)$。只有匹配总体视觉边缘分布的负例和原始配对正例，才得到常数项之内的边缘对数似然比。另九照正例改变了正样本分布。实例和主体分数也都读取当前脑电，其中共享证据可能被重复累积。下面继续把这些分数作为经验能量在留出图像上检验。一个概率化分解可用 $\log p(x_\mathrm{inst}\mid T)+\log p(x_\mathrm{sem}\mid x_\mathrm{inst},T)$，其中第二项须用条件对照估计。 [InfoNCE 密度比](https://arxiv.org/abs/1807.03748) · [源空间优化 D-Flow](https://proceedings.mlr.press/v235/ben-hamu24a.html)

在固定布局的同种子成图中，真相对 token 显示可利用的主体信息，现有读出和先验的收益尚未覆盖这项差距。下一轮冻结 D2 和生成器其余路径，只在第四次 U-Net 的图像 Value 投影加入一个零初始化的秩四更新。图像 token 的共同均值记作 $m=\tfrac14\sum_jT_j$，可训练的 Value 为

$$
V_j = W_V T_j + U D (T_j-m),\qquad U_0=0.
$$

三组共享同一批真实训练 EEG、噪声和初始化。完成的 RGB 图像由冻结 DINOv2 提取图块特征，训练目标分别使用原图均匀图块、同类另九照均匀图块和同类另九照前景图块。交换只发生在新增项中的相对输入，原始注意力、前三步结果和布局共用。该开发试验同时报告正配相对错配的成图差和原照保持程度。 [训练和成图入口](code/paper_terminal_relative_attention.py)

令 $S^+_{ab}$ 为正确输入时第 $a$ 张生成图的各 DINO 图块与参考 $b$ 的余弦相似度的平滑最大值。$S^-_{ab}$ 使用交换后的新增输入。对每一对相近构图的异物体，计算正确参考超过对方参考的边际 $m^\pm_a=S^\pm_{aa}-S^\pm_{ab}$。训练损失为

$$
\mathcal L = \operatorname{CE}(S^+/\tau)
+\tfrac12\operatorname{mean}_a \operatorname{softplus}
\left(\frac{m^-_a-m^+_a}{\tau}\right)
+ \tfrac12 \operatorname{MSE}\!\left(P_8(z^+),P_8(z_{\rm D2})\right).
$$

$P_8$ 表示对潜变量作 $8\times8$ 平均池化。其约束保留低频构图。全部原生 token 坐标继续参与注意力。秩四约束只限定每个新增的 Value 更新。

## 跨构图的主体配对读出

第一组在十名被试的 13,230 张训练照片上为每对相近布局的异物体 EEG 选取两对独立参考照片。两个训练臂共用同一对 EEG、同样四张参考和同一初始化。参考组内匹配与交换的布局距离分别为 .9201 和 1.1896。每个参考位置的正确减交叉配对边际为 $D^\top V_j$，其中 $D=q_a-q_b$，$V_j=v_{a,j}-v_{b,j}$。交换同一批参考时，两项边际的均值仍是 $D^\top(v_{a,1}+v_{a,2}-v_{b,1}-v_{b,2})/2$。训练损失因 softplus 的非线性而有区别。两种读出在 50 类复核组的首位均为 23/5,000，成图前预测的平均余弦为 .999984。回执与本轮精确代码保存在 `cross-photo-layout-20261127`。 [训练入口](code/paper_cross_photo_layout.py)

第二组为同两个物体各选两张不同照片提供 EEG，并另选四张照片作为参考。每个物体的两张 EEG 照片与两张参考照片互不重复。两对真实 EEG 来自同一被试和不同构图。场景内异物体的平均布局距离为 .8522，两个场景之间为 1.4565。同构图与反向构图参考相对其 EEG 的距离分别为 1.0407、1.2867。两臂共享四段 EEG 和四张参考，交换的是两对完整参考与两对 EEG 的对应关系。设两对 EEG 的差向量为 $D_1,D_2$，两对参考的差向量为 $V_1,V_2$，则

$$
\Delta_{\mathrm{aligned}}-\Delta_{\mathrm{opposite}}
=(D_1-D_2)^\top(V_1-V_2),
$$

其中 $\Delta$ 为两个配对边际之和。因此交换直接改变了优化所用的平均边际。三组由同一个四时段全头皮编码器继续训练 12 轮、840 次更新。各组访问相同的 EEG 端点、视觉监督与训练照片。
