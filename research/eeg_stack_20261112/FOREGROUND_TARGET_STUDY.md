# 用前景视觉特征监督 EEG 主体读出

训练照片中的主体和背景会一起进入全图视觉特征。这个实验固定训练照片、物理 EEG、读出容量、基础编码器和生成器，改变用于训练的视觉目标。要检验的是让训练更重视主体位置后，实际画出的物体是否更容易辨认。[此前的波形实验](REPEAT_NOISE_READOUT_STUDY.md)

此前用同一批掩膜换成中性背景，再通过 Brain-HiVE 的视觉模型重新提取特征。开发 R4 两人的成图命名，整图训练为 6/400，前景训练为 2/400。这里保持原始 RGB，在另一视觉模型的同一组 patch 上只改变聚合权重。

## 只改变训练图像特征

在同一批 13,230 张已登记训练照片上运行冻结的 DINOv2-S/14，保留 $16\times16$ 个 patch 向量。将固定 U2NetP 前景掩膜以相同坐标裁剪到 224 像素，再取每个 patch 内的均值。令 $p_{ij}$ 是训练图 $i$ 的第 $j$ 个单位 patch 向量，$m_{ij}$ 是对应的平均前景权重。每种训练视图的目标为

$$
v_i=\operatorname{unit}\left(\sum_j w_{ij}p_{ij}\right).
$$

均匀组取 $w_{ij}=1$。主体组取 $w_{ij}=m_{ij}$，掩膜偏移对照将同一组权重同时上下和左右循环移动 8 个 patch。三组使用同一次视觉模型前向，偏移保留每张图的权重分布。空掩膜回退到均匀权重。最后一层 patch 本身已包含全图上下文，因此权重改动衡量的是主体位置对聚合的贡献。

## 训练与比较

在每位被试内，先对实际 EEG 呈现取均值，再用 0–800 毫秒的 20 毫秒窗和原有 17 个后部电极构造 680 维输入。三组各拟合一套相同岭正则的 EEG 到视觉视图映射，再用同一训练集学习该视图到 160 维连续语义空间的映射。

先在登记训练类四折中按整个物体留出。每折有独立的 EEG 到视觉拟合和视图到 DINOv2 全图 CLS 映射。评分时用 1,323 类原型比较，每条查询的真类原型排除对应的原照片。另在开发集和官方面板从单条 EEG 估计语义坐标。评分代码再读取全部 1,854 个名称，报告并列计分后的 Top-1 和 Top-5。

生成条件中，原生 Brain-HiVE 映射的连续语义坐标和四个图像 token 来自当前查询。每组把原生语义和新读出各保留一半。均匀、偏移和错配对照的坐标范数逐行匹配主体组，以比较方向。错配组只调换新增的主体读出。所有推理条件使用当前查询的同一批物理呈现。掩膜属于训练输入，词表与参考照片用于评分。[视觉目标、读出与成图实现](code/paper_foreground_targets.py)

## 结果

| 聚合方式 | 原始视觉特征辨认物体 / 13,230 | 整类折外 EEG Top-1 / 52,920 | 整类折外 EEG Top-5 / 52,920 |
| --- | ---: | ---: | ---: |
| 均匀 | 10,494 | 330 | 1,518 |
| 主体 | 10,837 | 337 | 1,458 |
| 偏移 | 8,552 | 312 | 1,429 |

全图 CLS 作为原始视觉特征时认对 11,505/13,230。改主体权重后，视觉模型比均匀 patch 认对多 343 张。到了 EEG 读出，四人的首位只多 7 次，前五少 60 次。

四位被试各提供 200 条查询。主体、均匀与偏移三组在每个预算的首位积分相同。主体组低于原生照片映射的 R4 首位和 R80 前五。该候选完成了成图前读出比较，未进行新一轮成图。此前中性背景实验的 2/400 来自真实的生成图。[各折与各被试分数](results/foreground_target_study.json)

## 复现

沿用[基准环境](PAPER_BENCHMARK_PROTOCOL.md)和登记训练掩膜。设置实验结果目录、每位被试的原生 Brain-HiVE 检查点目录。在计算节点执行。

~~~sh
python paper_foreground_targets.py prepare "$MASKS_TRAIN"
python paper_foreground_targets.py fit 1
python paper_foreground_targets.py infer 1 --budgets dev-r4 official-r4 official-r80
python paper_foreground_targets.py score 1 --budgets dev-r4 official-r4 official-r80
~~~
