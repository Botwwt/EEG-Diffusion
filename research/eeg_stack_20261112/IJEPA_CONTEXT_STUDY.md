# 用 I-JEPA 的遮挡预测误差监督 EEG 图像条件

早期实验用 VAE 网格邻块回归，检验 EEG 能否保留周围画面解释不了的照片细节。本次用官方预训练 I-JEPA 的完整检查点，保留同一张原照在 Brain-HiVE 生成器里的四个图像 token，并将 I-JEPA 额外监督接到决定主体较多的相对 token 分量。[早期局部残差实验](../../docs/CONTEXT_RESIDUAL.md) · [照片条件交换结果](TOKEN_EVIDENCE_STUDY.md) · [I-JEPA](https://arxiv.org/abs/2301.08243)

## 训练照片的平均误差和自身误差

从 1,323 个登记物体读入各自十张训练照片。冻结官方 ViT‑H/14 的上下文编码器、EMA 目标编码器和预测器。将 224×224 图像划分为 $16\times16$ 个 patch。依次藏住四个象限之一。上下文编码器从第一层注意力开始就只处理可见 patch。预测器为每个隐藏位置预测表示，完整照片只交给 EMA 目标编码器。

令 $z_{ip}$ 是训练照片 $i$ 的目标 patch 表示，$\hat z_{ip}$ 是在藏住该 patch 所在象限后，从其余位置预测的表示。取各特征坐标的平均 Smooth L1 作为误差

$$
e_{ip}=\operatorname{mean}_{d}
\operatorname{SmoothL1}\bigl(\hat z_{ipd},z_{ipd}\bigr).
$$

在训练集每个物体固定抽取一张照片，得到每个位置 $p$ 的误差均值 $\mu_p$ 与标准差 $\sigma_p$。将 $\mu$ 在位置轴上标准化得到 $a_p$。自己的误差图使用 $a_p+\operatorname{clip}((e_{ip}-\mu_p)/\sigma_p,-4,4)$ 作权重的 logit。训练平均组只用 $a_p$。同物体换图组使用同一物体另一张训练照片的偏差，然后仍用这些权重聚合当前照片的真实表示 $z_{ip}$。三个组都将一半权重等分到所有 patch，另一半取 logit 的归一化指数。三种教师向量按同一训练集 PCA 投影到 512 维。

因此比较的是**照片自己的上下文预测误差能否指出值得学习的位置**。同物体换图保留物体身份、原照 token、误差权重的分布以及训练预算。同类十图内没有照片自配。已有工作探索过对齐视觉 patch 和在 EEG 本身做 JEPA 预训练。这里复用的是图像侧的冻结遮挡预测器，测试照片特有误差对实际主体重构的作用。[I-JEPA 完整权重和代码](https://github.com/facebookresearch/ijepa/tree/52c1ae95d05f743e000e8f10a1f3a79b10cff048) · [RPA 视觉 patch 解码](https://arxiv.org/abs/2609.31698) · [EEG-JEPA](https://arxiv.org/abs/2608.00114) · [训练目标提取](code/paper_ijepa_context.py)

## 监督生成器接收的相对 token

每张训练图有冻结 Brain-HiVE 条件 $T_i$。模型以该被试四次 EEG 的算术平均预测 $\hat T_i$。保持原生的精确照片 token 对比和回归损失。再将 $\hat T_i$ 减去自己的四 token 均值，用真图相对 token 的已登记 512 维训练坐标读出。相同容量的辅助头把这个读出与对应 I-JEPA 教师做双向对比，系数为 0.5。每组从同一个个人 BrainMLP 开始，共 360 次更新。推理时使用训练完成的 BrainMLP 和原有冻结生成器。

实际成图使用两个开发被试各自 200 张整类留出照片。各方法使用相同四次物理呈现、同一逐刺激种子、空提示和四次 SDXL-Turbo U-Net 计算。用同一个模型替换为另一物体的 EEG 作对照。1,854 个物体名称和原照由独立评分阶段读取。[训练、生成及评分](code/paper_ijepa_supervision.py) · [基准协议](PAPER_BENCHMARK_PROTOCOL.md)

## 误差图给了主体多少权重

在 1,323 个登记训练物体上各取两张未参与误差位置校准的照片。以已登记的 U2NetP 软掩膜近似主体。把掩膜降采样到相同 $16\times16$ 网格，计算权重落在掩膜内的软质量。均匀权重为 33.22%，平均误差图为 27.86%，同物体换图为 27.84%，自己的误差图为 27.17%。自己的误差图相对平均误差图少给主体 0.69 个百分点，按物体配对重采样的 95% 区间为 [−0.81, −0.57]。这个诊断使用训练照片，数值取决于自动前景分割。

追加实验让三组使用当前训练照片的同一个软前景作为权重的基底。令 $q_{ip}$ 是归一化前景掩膜，$b_{ip}$ 是各组原有 logit。实际权重变为

$$
w_{ip}=\frac12q_{ip}+\frac12\frac{q_{ip}\exp b_{ip}}{\sum_jq_{ij}\exp b_{ij}}.
$$

掩膜为零的位置权重为零，空掩膜回退到整图均匀基底。仍用原来的 I-JEPA 误差位置校准、同一生成器下的原照 token 目标和同样的训练预算。推理使用单人的四次 EEG，掩膜只作用于训练照片。[前景约束的实现](code/paper_ijepa_context.py)

## 成图前的独立折外读出

四位被试各用 13,230 条真实四次 EEG。每轮留下一个完整物体折，用另外三折拟合 EEG 到视觉教师、以及该视觉教师到同一冻结 DINOv2 空间的岭回归。四折使用预先准备的视觉 PCA。评分时比较 1,323 个训练物体原型，正确物体的原型排除当前照片。直接预测 DINOv2 是参考项，该组的训练目标与评分空间一致。

| 视觉教师 | 用真照表征认对物体 / 13,230 | EEG 首位 / 52,920 | EEG 前五 / 52,920 |
| --- | ---: | ---: | ---: |
| 平均误差 | 5,634 | 300 | 1,398 |
| 照片自身误差 | 5,560 | 305 | 1,369 |
| 同物体换图误差 | 5,619 | 296 | 1,373 |
| 直接 DINOv2 教师 | — | 385 | 1,656 |

自己的误差图使首位多五次，前五少二十九次。该比较衡量真实 EEG 在固定线性读出下的物体判别能力。成图使用前面单独训练的非线性 EEG 编码器。[折外读出实现](code/paper_ijepa_probe.py)

在前景组内重新拟合同一个供三组共享的 PCA。前景内的平均误差、自己的误差和换图误差，用真照表征分别认对 5,864、5,805、5,849 个物体。对应的折外 EEG 首位为 294、299、295，前五为 1,338、1,330、1,328。将自己的误差限制在前景后，真照层的命中从 5,560 增至 5,805，实际 EEG 的首位从 305 变为 299。两组分别拟合视觉 PCA，因此这项跨组比较也包含视觉目标坐标的改变。

## 重放

使用已登记的训练 JPEG、训练照片顺序表和原始 17 通道 EEG 身份清单。按外部仓库的固定提交准备官方 I-JEPA 代码，将上游完整检查点下载到本地，并检查散列 `0382013c481743e9ccea89f970bc6c6aa126aa19a62127500d6e672a641aae22`。在 GPU 工作节点或本地 GPU 上提取教师，训练和真实成图沿用基准的设备配置。

```sh
code=research/eeg_stack_20261112/code
python "$code/paper_ijepa_context.py" \
  --prep "$BENCHMARK_PREP" --eeg-ids "$EEG_TRAIN_IDS" \
  --upstream "$IJEPA_SOURCE" --checkpoint "$IJEPA_WEIGHTS" \
  --sha256 0382013c481743e9ccea89f970bc6c6aa126aa19a62127500d6e672a641aae22 \
  --images "$TRAIN_IMAGES_ZIP" --output "$EEG_CROSSFIT_ROOT/targets.pt"
python "$code/paper_ijepa_supervision.py" fit 1
python "$code/paper_ijepa_supervision.py" infer 1
python "$code/paper_ijepa_supervision.py" score 1
```

前景组取独立的 `EEG_CROSSFIT_ROOT`。目标提取额外给 `--foreground "$TRAINING_MASKS"` 和 `--calibration "$CONTEXT_RUN/targets.json"`。此后对每个被试沿用相同的训练、成图和评分命令。
