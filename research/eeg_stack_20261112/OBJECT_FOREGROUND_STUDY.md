# 按照片配对训练 EEG 主体编码器

连续语义实验的真实视觉输入能读出物体名，EEG 输入的同一读出命中很少。这次从个人 Brain-HiVE 权重开始，直接训练 EEG 编码器输出物体语义坐标。生成器同时接收该编码器的连续语义条件和由原生 EEG 编码器生成的图像条件。[上一轮实验](REPEAT_SEMANTIC_BRIDGE_STUDY.md) · [Brain-HiVE 实现](https://github.com/ssshamiii/Brain-HIVE)

## 训练

四位被试分别训练。每个训练物体使用十张照片，每张照片使用四次真实 EEG，合计 1,323 个物体与 13,230 张照片。每种条件训练十二轮，共 840 次更新。两个编码器使用相同初始化、训练物体顺序、训练 EEG、损失权重和 160 维连续语义目标。初始线性头由训练照片特征拟合，语义训练更新整个 EEG 主干。

照片按 (4	imes4) 分格，取外围十二格的 RGB 均值与标准差。该特征以照片边缘的颜色和纹理近似背景。对于同一个物体，从十张照片的十六种随机配对中，选取边缘特征距离总和最大的配对。每张照片每轮各用一次。随机配对对照用同一候选序列的第一种配对，批内错配按固定顺序取。背景配对组从当前批次的其他语义标签中选边缘特征最近的照片。训练准备时核对的同类配对平均平方距离从 1.684 增至 2.051。[边缘特征与配对](code/paper_background_pairs.py)

用 (s_{ij}=cos(z_i,t_j)) 表示第 (i) 个 EEG 表征与第 (j) 个训练物体目标的余弦相似度。对两个物体 (a,b)，配对损失为

=operatorname{softplus}left(rac{s_{ab}+s_{ba}-s_{aa}-s_{bb}}{2	au}ight),

同一物体的两张照片各自提供一份四次平均 EEG。训练还用两份波形的均值预测同一物体。总损失是三种输入各自的类别交叉熵均值，加上 0.30 倍连续坐标误差、0.15 倍同物两张照片的方向差，以及 0.35 倍配对损失。[训练实现](code/paper_object_foreground.py)

## 成图比较

四次呈现的开发组来自第 01、03 名被试，各 200 张整类留出照片。第 02、04 名被试在正式 200 张照片上做八十次呈现的探索性对照。每位被试的各组使用相同 EEG 呈现、原生图像 token、种子和 SDXL-Turbo 的一次四步生成。固定语义组接收训练语义均值。错配只轮换连续语义，轮换顺序预先固定。生成阶段使用单个查询的 EEG，词表和参考图由评分阶段读取。主指标在 1,854 个物体名称中对已生成图像评分，并列按比例计分。[生成及评分](code/paper_object_foreground_render.py)

| 条件 | 开发 R4 主体 / 400 | 官方 R80 主体 / 400 | 开发 R4 原照 / 400 | 官方 R80 原照 / 400 |
| --- | ---: | ---: | ---: | ---: |
| Brain-HiVE | 5 | 9 | 10 | 43 |
| 固定语义 | 3 | 9 | 11 | 47 |
| 随机配对训练 | 8 | 9 | 16 | 47 |
| 按背景配对训练 | 7 | 9 | 14 | 46 |
| 按背景配对训练，语义错配 | 8 | 6 | 13 | 44 |

四位被试重跑的 800 张基线图与已有归档逐张哈希一致。按背景配对的开发组比 Brain-HiVE 多两个自动命中，差 +0.50 个百分点，95% 区间 [−1.00, +2.25]。对相应错配组的差为 −0.25 个百分点，区间 [−2.00, +2.00]。官方 R80 比 Brain-HiVE 的差为 0.00，区间 [−1.50, +1.50]。在官方 R80 上，两种配对训练逐查询的主体命中相同。区间按被试与共享刺激配对重采样，开发组以整类照片为刺激重采样单位。官方 R4 仅有下面的成图前读出。

核对发生自动命中变化的图片。开发组的骰子命中可对应一堆圆片或方形图案。官方组的羔羊在各条件下仍是几乎相同的棕色四足动物。海藻保持树木状，护栏、水蛭和画笔的固定样例分别仍像杯子、管子和鸟。自动标签的得失包含评分器对相近画面的区分波动。

另对开发组每一张照片，在评分时选边缘特征最接近的另一类照片，比较两条 EEG 与两种物体目标的正配相似度和错配相似度。400 个有方向的配对比较中，原生融合特征接照片拟合映射取胜 328 次，随机配对训练 315 次，按背景配对训练 318 次，语义错配 186 次。配对共享样本，计数衡量此面板上的趋势。生成程序不读取这些配对。

## 语义进入生成器的位置

在第 01 名被试的同一 200 张开发照片上，把前两步的原生图像 token 缩放至 0.25，最后两步用原始 token。语义条件保留原幅度或加倍，坐标范数上限取训练目标分布的第 95 百分位。四步 U-Net、种子和 EEG 物理呈现与原比较一致。原先完整图像条件的背景配对组为 6/200。

| 前两步减弱图像条件 | 主体命名 / 200 | 找回原照 / 200 |
| --- | ---: | ---: |
| EEG 语义，原幅度 | 4 | 4 |
| EEG 语义，原幅度错配 | 2 | 4 |
| EEG 语义，双倍幅度 | 4 | 5 |
| EEG 语义，双倍幅度错配 | 1 | 4 |

做单独的真实照片诊断。语义映射用原登记训练照片特征拟合，诊断查询用真实留出照片特征产生语义。生成器的图像条件依然来自该行 EEG。两种时序各有正配和错配真实照片特征。该组用于测量生成器对较准确语义的响应。

| 真实照片特征诊断 | 主体命名 / 200 | 找回原照 / 200 |
| --- | ---: | ---: |
| 完整图像条件，正配语义 | 12 | 34 |
| 完整图像条件，错配语义 | 4 | 3 |
| 前两步减弱图像条件，正配语义 | 34 | 39 |
| 前两步减弱图像条件，错配语义 | 2 | 0 |

前两步减弱图像条件时，诊断正配语义相对错配多 32 个自动命中，按开发物体重采样的 95% 区间为 [+8.50, +24.50] 个百分点。固定样例中的护栏和画笔在正配真图条件生成后可以辨认。相同位置的 EEG 输出仍接近花箱和动物。较强的准确语义可以改变生成主体，实际 EEG 读出在这一设置下还未达到该效果。[时序实现](code/paper_object_semantic_timing.py)

## 复跑

使用[基准环境](PAPER_BENCHMARK_PROTOCOL.md)，并准备上一轮的 160 维语义基底。令 `EEG_CROSSFIT_ROOT` 指向结果目录，`EEG_RUNS_ROOT` 指向相应个人原生权重目录。在计算节点执行以下命令。

```sh
python paper_background_pairs.py
python paper_object_foreground.py train 1
python paper_object_foreground_render.py infer 1 --budgets official-r4 official-r80 dev-r4 --render-budgets dev-r4
python paper_object_foreground_render.py score 1 --budgets official-r4 official-r80 dev-r4 --render-budgets dev-r4
```

从四位被试收集成图前读出后，运行 `paper_object_pair_diagnostic.py` 可得到背景匹配的配对计数。时序实验使用仓库中支持逐步图像 token 的 `paper_render.py` 与对应 rollout 实现。

```sh
python paper_object_semantic_timing.py 1
python paper_object_semantic_timing.py 1 --real-photo-diagnostic
```
