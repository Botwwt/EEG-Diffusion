# 分离试次波动和照片差异的 EEG 主体读出

上一轮将真实照片特征提供给生成器时，减弱前两步的原生图像条件能让护栏和画笔变得可辨认。相同处理用回实际 EEG 后没有测到改善。这一轮在同一连续语义空间内，单独估计同一照片的试次波动与同一物体不同照片的响应差异，再按实际 EEG 重复数计算主体条件。[上一轮成图与时序对照](OBJECT_FOREGROUND_STUDY.md)

## 估计方法

每位被试用 1,323 个训练物体、13,230 张训练照片及每张四次物理记录训练。每条记录使用原生 Brain-HiVE 第一层的 1,024 维线性投影，加 17 个通道各 40 个 20 毫秒窗口均值。两部分都是线性变换，因此先平均波形与先变换再平均给出相同的特征。

令 $x_{ikr}$ 表示第 $k$ 个物体的第 $i$ 张照片、第 $r$ 次物理呈现。先求四次均值 $\bar x_{ik}$。四次均值的试次协方差 $\widehat N_4$ 由每张照片的四次残差估计。另一协方差由 $\bar x_{ik}$ 减去对应物体的十照片均值估计，再减去 $\widehat N_4$，得到同一物体的照片差异 $\widehat P$。两者都在四次均值的正则化协方差下变换并截断到半正定。试次噪声的协方差特征值上限为 0.95，照片差异的上限为 1。

令 $C$ 为训练物体的平均 EEG 特征与连续语义目标的交叉协方差。在变换后的坐标内，普通岭回归的权重为 $C$。设 $R$ 为查询的物理重复次数，读出权重为

$$
W_R = \left[I-\left(1-\frac{4}{R}\right)\widehat N_4+0.75\,\widehat P\right]^{-1}C.
$$

$4/R$ 是独立同分布试次噪声下的近似。实际记录可能有共享波动。另将每条八十次查询按奇偶重复分为两个四十次均值，检查训练方差方向在留出记录中的重复程度。检查结果只用于分析，拟合使用登记训练数据。[训练与推理实现](code/paper_repeat_noise_readout.py) · [可重复脑电分量的原始研究](https://arxiv.org/abs/1407.6110)

## 生成和对照

连续条件以一半原生照片映射、一半调整后的 EEG 读出构成。等强度组保留普通岭回归混合的方向，令坐标范数与逐图的调整组相同。错配组只轮换调整后的读出，原生语义映射和图像 token 仍来自当前接收者。所有组以训练语义坐标范数的第 95 百分位为上限。生成模型逐图接收单人 EEG，训练阶段才使用已登记的照片特征与文字。参考照片和 1,854 词表由后续评分读取。

第 01、03 名被试在 200 张整类留出开发照片上使用四次呈现。第 05、06 名被试在 200 张官方照片上使用八十次呈现。两组各自对 Brain-HiVE 使用同一人、同一批实际呈现、同样种子和一次四步 SDXL-Turbo。官方四次也检查成图前的语义读出。

## 核对相邻图像在采集中的重叠

原始实验的图片起始时间相隔 200 毫秒，公开事件表记录了每张图的位置。用 NEMAR 的固定事件版本和作者预处理的随机顺序重建训练试次。Brain-HiVE 导出的数据按场次保存各组，场次内保留作者对两次记录的重排。只纳入恰有四条候选记录且能与释放文件场次索引吻合的照片。每对图片都在登记训练集内。[原始实验](https://pmc.ncbi.nlm.nih.gov/articles/PMC9771828/) · [公开事件表](https://github.com/nemarDatasets/nm000232/tree/cf0540ffd250d8681ef31a9a9e345f5053e4c90b) · [顺序核对实现](code/paper_rsvp_training_context.py)

| 训练采集核对 | 01 | 03 |
| --- | ---: | ---: |
| 当前图与下一图的相邻试次对数 | 36,692 | 36,905 |
| 同次采集的同一波形片段相关 | .994 | .989 |
| 换成下一图在同场次的另一次呈现 | .212 | .177 |
| 下一图另一场次的独立响应与当前后段相关 | .246 | .206 |
| 用相同场次的其他照片作模板 | .188 | .155 |

同次采集的波形匹配核对了实际时序。换成独立场次后，真实下一张照片比另一张照片更能解释当前 EEG 的后段。事件表在训练分析中确定相邻关系，实际测试查询仍只提供本图 EEG。

## 按已知呈现顺序拟合独立的图片响应

令 $v_i$ 是训练照片 $i$ 的 128 维视觉特征。对连着出现的三张训练照片 $(p,c,n)$，分别拟合当前试次 0–200 和 200–400 毫秒的脑电。两个时间段共享对单张照片的响应参数。

$$
\begin{aligned}
E_{0:200} &\approx H_0 v_c+H_1 v_p \\
E_{200:400} &\approx H_1 v_c+H_0 v_n
\end{aligned}
$$

普通核对照固定相邻图片的两项为零，使用同一批三图序列、正则化和视觉特征。整类留出核验将折 4 的物体在序列三个位置全部排除在拟合之外。评估时比较对留出当前响应的预测误差，并交换前后图片来核对顺序的作用。这一步的模型输入是留出照片的视觉特征。真正的 EEG 读出只应用到当前波形，以训练得到的 $(H_0v_c,H_1v_c)$ 估计语义所需的交叉协方差。两个读出共用实测 EEG 协方差和相同的语义融合方式。[时序训练与盲读出](code/paper_rsvp_deconvolution.py)

| 训练整类留出核验 | 01 | 03 |
| --- | ---: | ---: |
| 普通核预测误差（MSE） | .53303 | .40066 |
| 用真实呈现顺序分离后的预测误差 | .52786 | .39543 |
| 分离模型使用错配顺序时的误差 | .54233 | .40805 |
| 真实顺序优于错配的试次 | 5,069/6,592 | 5,146/6,639 |

| --- | ---: | ---: | ---: |
| 原生照片映射 | 0 / 3 | 0 / 4 | 5 / 18.5 |

训练类的顺序核能更好地预测留出的波形。只给当前 EEG 时，开发 R4 在首位和前五均与普通核持平。官方 R80 多 1 个首位积分，前五持平，并低于原生照片映射的前五积分。这一候选评估停在成图前读出。[两位被试的训练和读出记录](results/repeat_noise_readout_study.json)

## 复现

沿用[基准环境](PAPER_BENCHMARK_PROTOCOL.md)和上一轮的 160 维语义基底。令 `EEG_CROSSFIT_ROOT` 指向结果目录，`EEG_RUNS_ROOT` 指向相应个人原生权重目录，在计算节点执行。

```sh
python paper_repeat_noise_readout.py train 1
python paper_repeat_noise_readout.py infer 1 --budgets official-r4 official-r80 dev-r4 --render-budgets dev-r4
python paper_repeat_noise_readout.py score 1 --budgets official-r4 official-r80 dev-r4 --render-budgets dev-r4
```

冻结四人的成图前读出后运行 `paper_repeat_noise_agreement.py`，可复核两份物理 EEG 的一致性与语义命中。时序核验从固定 NEMAR 修订获取四个场次、每场次五个训练运行的 `events.tsv`。事件目录同时包含各人的原生 `sub-XX_train.npy` 场次索引，以及记录修订、文件来源、SHA-256 和事件行数的 `receipt.json`。

```sh
python paper_rsvp_training_context.py prepare 1 "$EVENTS_DIR" "$RAD_ROOT/data/prep/paper_split.json" "$CONTEXT_DIR"
python paper_rsvp_training_context.py audit "$CONTEXT_DIR/sub-01-training-context.npy" "$RAD_ROOT/data/prep"
python paper_rsvp_deconvolution.py fit 1 --context "$CONTEXT_DIR"
python paper_rsvp_deconvolution.py infer 1
python paper_rsvp_deconvolution.py score 1
```
