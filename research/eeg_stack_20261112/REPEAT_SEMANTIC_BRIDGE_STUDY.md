# 连续语义条件的 EEG 成图实验

主指标是成图中的主体。沿用官方 200 张原图和冻结的 CLIP-L/14 评分器，按 1,854 个物体名称的首位命中计分。重名并列分享分数。生成模型的逐图输入只有当前被试的真实 EEG。数据清单用于核对 EEG 行顺序，评分程序读取完整词表和参考原图。每条 EEG 与 Brain-HiVE 使用相同 80 次物理呈现、逐图种子、SDXL-Turbo 和一次四步采样。四位被试的重跑基线与已有归档的 800 张 PNG 逐张哈希一致。

## 训练与扰动

先用 Brain-HiVE 得到融合特征，再把特征映射到连续 SDXL 文本状态。图像条件也取自该查询的 Brain-HiVE 特征。文本状态的均值和基底用 1,323 个训练概念构造，照片映射用这批概念的真实视觉特征拟合，EEG 映射用同一批概念的留概念外预测特征拟合。每个训练概念在产生自身的 EEG 预测时，整类十张照片都从对应编码器的训练中留出。

以标准化特征 (f_{kj}) 表示概念 (k) 的第 (j) 张照片，(ar f_k) 是概念均值，(s_k) 是其中心化的连续文本坐标。用照片映射的权重 (W_{mathrm{photo}}) 约束 EEG 拟合。

重复一致性分支将物理呈现分为互不重叠的等长子组，估计每个语义坐标的组间一致性，再衰减分歧较大的坐标。错配组只轮换语义条件，图像条件仍来自接收样本。固定软条件只用训练均值，以估计文本状态均值本身对生成器的影响。[实现](code/paper_repeat_semantic_bridge.py)

## 成图前读出

被试 01、02、03、04 各提供 200 个查询。用 SDXL 冻结的 pooled 文本状态计算名称排名，位于生成程序之外。四次条件取同一批物理呈现的前四次。

| 连续条件 | 四次 Top-1 / Top-5 | 八十次 Top-1 / Top-5 |
| --- | ---: | ---: |
| 照片映射 | 4 / 7.75 | 8 / 36 |
| EEG 映射 | 3.25 / 9.75 | 7 / 22 |
| 重复一致性 | 1.25 / 8 | 7 / 25.75 |

在被试 02、04 上进一步以配对训练照片可预测的文本变化为目标，重建 160 维语义基底。八十次照片映射的首位命中从 3 增至 4.25，前五命中从 23 变为 22.75。EEG 映射的首位命中都是 3。两位被试的照片映射前五命中一升一降。扩大语义空间的实验停在读出阶段。[训练照片指导的基底](code/paper_semantic_basis.py)

将真实测试照片的融合特征代入同一个映射，48 维和 160 维读出分别得到 44.25/200 和 93.25/200，前五分别是 92/200 和 154/200。换回被试 02 的 80 次 EEG 特征后，两个读出的首位命中分别为 2/200 和 3.25/200。真实照片特征只用于这个离线诊断。扩大基底能保留更多真实视觉特征中的类别信息，相同的优势在 EEG 特征上很小。

## 成图初验

被试 01 和 03 在同一 200 张官方照片上分别渲染，每组有 400 张图。

| 条件 | 主体命名 | 找回官方原照 | SSIM |
| --- | ---: | ---: | ---: |
| Brain-HiVE | 4 | 42 | .31266 |
| 固定软条件 | 3.5 | 32 | .32108 |
| 照片映射 | 6.5 | 34 | .32116 |
| EEG 映射 | 4 | 26 | .32136 |
| EEG 映射错配 | 4.5 | 33 | .32009 |
| 重复一致性 | 2 | 31 | .32105 |
| 重复一致性错配 | 4.5 | 39 | .31942 |

照片映射相对 Brain-HiVE 的主体命名差为 +0.625 个百分点，按被试和刺激配对重采样的 95% 区间为 [−1.00, +2.13]。EEG 映射和重复一致性分支的正确条件得分都低于相应错配。照片映射的自动命名变化包含真实画面变化和评分器差异。被试 03 第 175 行从马甲变为可辨认的西装。被试 01 第 037 行的奶酪在固定软条件中也已明确可辨。第 089 行的连续语义图被判成手榴弹，人工看图接近缺少拉环的瓶状物。第 013 行的自行车在三个条件下依然可辨，评分标签分别变为 `bike`、`gazelle` 和 `scooter`。

## 新被试复核

在被试 02、04 的同一官方照片面板上复核照片映射，并为四位被试都生成照片映射的语义错配对照。每个查询保留本人的图像条件。错配只将连续语义条件移到另外一张照片的 EEG 查询。

| 条件 | 新被试主体命名 / 400 | 四人主体命名 / 800 | 四人找回官方原照 / 800 |
| --- | ---: | ---: | ---: |
| Brain-HiVE | 9 | 13 | 85 |
| 固定软条件 | 9 | 12.5 | 79 |
| 照片映射 | 5.25 | 11.75 | 77 |
| 照片映射错配 | 6 | 12 | 68 |

新被试的命名差为 −0.94 个百分点，95% 配对区间为 [−2.50, +0.50]。四人的合计包含用于选条件的初验，描述性差为 −0.16 个百分点，区间为 [−1.50, +1.19]。正确语义条件相对错配的命名差为 −0.03 个百分点，区间为 [−1.56, +1.28]。新增被试仍处于 R80 条件。本实验的 R4 结果覆盖成图前读出。

初验的西装在错配条件下也出现。被试 04 第 150 行的机器人自动命中对应手持蓝色机械部件的人。被试 02 第 171 行的新条件和 Brain-HiVE 都能看出旅行车，错配图变为动物。记录支持连续软条件能改变成图，主体命名收益在新被试中未复现。[分数与逐条变化](results/repeat_semantic_bridge.json)

## 重放

设定已有 [基准环境](PAPER_BENCHMARK_PROTOCOL.md)的 `RAD_ROOT`、`ARCHIVE` 与个人 `EEG_RUNS_ROOT`。将已有 `crossfit_generator/conditions-sub-01.pt` 等缓存放在基准目录，按被试设置 `EEG_CROSSFIT_ROOT` 为结果目录。先冻结生成输出，再运行读出与成图评分。将 `--readout-only` 同时传给两个命令可单独重放物体读出。

```sh
python paper_repeat_semantic_bridge.py render 1 official-r80
python paper_repeat_semantic_bridge.py score 1 official-r80
```

照片映射的附加实验用 `--arms soft-center photo-map photo-wrong` 选择条件。160 维读出用下列命令。生成和评分均应在计算节点运行。

```sh
python paper_semantic_basis.py "$EEG_CROSSFIT_ROOT/predictable-text-space.pt"
python paper_repeat_semantic_bridge.py render 2 official-r80 --readout-only --space "$EEG_CROSSFIT_ROOT/predictable-text-space.pt"
python paper_repeat_semantic_bridge.py score 2 official-r80 --readout-only
```
