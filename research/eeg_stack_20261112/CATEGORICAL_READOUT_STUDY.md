# 同一脑电读出下的连续预测、离散后验均值与模式

现有四步生成器在收到真图相对 token 时能画出不少正确物体。真实 EEG 读出在成图前的开放命名仍低。本轮直接测同一个训练模型的三种读出，检验离散组合的最高概率点是否比连续方向或同一后验的均值更适合成图。ICLR 2026 的 AVDE 使用预训练 VQ‑VAE 和分尺度自回归生成。本轮只在冻结生成器接收的 H/14 条件上学习视觉代码和脑电读出。 [真图条件干预](TOKEN_GATE_ZERO_STUDY.md#布局与相对-token-的交叉替换) · [AVDE](https://proceedings.iclr.cc/paper_files/paper/2026/hash/a4dfcbcfa1f0425cd18aafa35a68019a-Abstract-Conference.html)

## 训练与评分

把每张登记训练图同物体其余九张照片的单位 H/14 均值作为主体目标。对 13,230 个主体方向减去总体均值 $\mu$。在 1,024 维坐标系顺序拟合六组 192 个残差向量，每次减去当前最近向量后拟合下一组。用十名被试各自 17 个后部电极的四次真实波形训练。十人共用一个时间编码器，主体支持另有原照和训练名称目标。一共 20 遍训练和 1,400 次更新。比较三种读出时权重固定。 [训练与评分入口](code/paper_categorical_readout.py)

令 $b_{lk}$ 为第 $l$ 组的第 $k$ 个向量，$p_{lk}(x)$ 为脑电读出的分类概率。R80 将该人的 80 次真实呈现分为 20 个不重叠四次组，平均 logit 后归一化。解码前分别计算

$$
h_{\rm mean}=\mu+\sum_l\sum_k p_{lk}(x)b_{lk},\qquad
h_{\rm mode}=\mu+\sum_l b_{l,\operatorname*{arg\,max}_k p_{lk}(x)}.
$$

两者是加性重建在分解概率模型下的期望和最高概率代码组合。另有同一 EEG 网络直接输出的连续方向。归一化后再分别按 .25 权重混入同一冻结 H/14 原始读出。最终图像生成只收到当前被试的 EEG 条件。完整的 1,854 名称用于评分，独立 SigLIP2 通过仅用训练照片拟合的视觉桥作复查。

## 视觉代码与十人 R80

在官方 200 张真照的 H/14 表征上，无量化的两个词表命名得 184.25 和 139.25 积分，六级量化后为 14 和 12。与此同时，量化真图向量还能在 200 张原照中找回 147 张。高精度原照匹配和不完整的开放词汇语义在视觉编码端就能同时出现。此处的量化字典在训练类的跨照主体均值上拟合，比较范围是这套残差码。

模式混合相对原生 H/14，两个命名差为 −.513 [−1.425, +.250] 和 −.050 [−.600, +.500] 个百分点。原照首位差为 −3.10 [−5.85, −.30]。独立 50 类的 5,000 条 R4 查询上，原生 H/14 得 29、26 个主体首位积分，模式混合得 23、27。第 3、4、6 级在完整官方 R80 上各只取过同一个代码。模式在独立头上的小幅改善没有转化为接入原生条件后的增益。

用同一字典、同一目标重新训练接收原生 D2 融合向量的头，验证这一结果对更强成图前表示是否成立。十人 R80 的独立连续、均值、模式分别为 `46 / 44`、`21 / 20.75` 和 `26.5 / 19.5`。混入连续方向后，双命名为 `51 / 37.25`，原照首位为 695。混入模式后为 `48.5 / 38.75` 和 655。相同指标的同人错配模式为 `40.5 / 38.75` 和 687。开发整类留出的双命名控制仍为原生 17、18，连续混合 17、19，模式混合 10、12。这里冻结的 D2 融合输入与正式主表的注册回执一致。该分支完成成图前测量。

### 用全维分位数恢复视觉编码能力

用训练主体的逐维四分位点与各区间内的平均值编码同一个 1,024 维向量。每维使用四个类别。以前述冻结 D2 输入、同一训练目标和 1,400 次更新比较。两条路线的脑电输入、训练顺序、留出概念和评分相同，类别分解与对应分类头的维数各自按表示确定。

| 真官方照片的输入方向 | H/14 主体 / 200 | SigLIP2 主体 / 200 | 原照首位 / 200 |
| --- | ---: | ---: | ---: |
| 完整 H/14 | 184.25 | 139.25 | 200 |
| 六级残差量化 | 14 | 12 | 147 |
| 逐维四分位数 | 179.25 | 127.75 | 200 |

分位数保留了大部分真图主体信息。对应的十人真实 R80 中，独立连续、后验均值和后验模式的主体成绩为 `46.5 / 35.5`、`10 / 22.25` 和 `29.5 / 19.5`。混入模式后，两个命名为 `48.5 / 34`，原照首位 690。混入错配模式后为 `46.75 / 38` 和 699。原生 H/14 是 `48.75 / 34.75` 和 734。整类留出开发的模式混合双命名为 `16 / 17`，原生 H/14 为 `17 / 18`。视觉量化可以保留主体，已试的脑电后验无法可靠恢复这些方向。这组结果来自成图前。训练脚本及回执在同一实验输出下的 `check-frozen-d2-posterior.py` 和 `quantile-frozen-d2/readout.json`。

在完整的 EEG‑EditBench 发布图像上另外测成图前向量。原生 H/14 挑出原照胜过换主体编辑的比率为 82.88%，原照胜过改属性编辑为 54.91%，在本刺激的所有编辑中取得首位为 11.75%。加入 17 导残差模式后依次为 80.41%、44.77%、7.90%。加入分位数模式后为 81.18%、46.98%、8.30%。分位数模式的换主体相对原生差为 −1.71 个百分点 [−2.85, −.60]。改用连续方向的换主体为 82.87%。编辑照片全程只由评分程序读取。回执为 `editbench-posterior.json`。 [公开编辑协议与评分](BACKGROUND_EDITBENCH_STUDY.md#eegeditbench-的发布口径)
