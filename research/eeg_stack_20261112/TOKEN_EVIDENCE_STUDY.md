# 图像注意力里哪部分带着物体信息

主指标是在成图上用完整的 1,854 个 THINGS 概念识别主体。每个候选使用一人的四次真实 EEG、空提示、一次生成和四次 U-Net 调用。逐刺激使用和 Brain-HiVE 相同的种子。另记录同物体十张照片中能否找回原照。

## 交换真图的两个条件分量

Brain-HiVE 在每张图上有四个投影后的图像 token。令 $T$ 是这四个向量，$m$ 是它们的均值，$R=T-\mathbf 1m$ 是每个 token 偏离均值的向量。图像注意力中，键和值是线性投影。对固定的查询 $Q$，公共项 $mW_K$ 给每条 softmax 加上相同的数。图像值的响应为

$$
\operatorname{Attn}(Q,T)
=mW_V+\operatorname{softmax}\left(\frac{Q(RW_K)^\top}{\sqrt d}\right)RW_V .
$$

公共项改变注入到所有查询位置的值。token 差异同时决定查询如何在四个 token 间分配权重，以及每个 token 向注意力输出提供的内容。这里在 Brain-HiVE 的同一模型、四步和种子上测试谁能保留目标物体。[Brain-HiVE 原生的图像注意力](https://github.com/ssshamiii/Brain-HIVE/blob/f06db69fcc4a029439e369c5c3dba6099e57560e/main/models_adapter.py) · [相关的全局与查询依赖值对照](https://arxiv.org/html/2501.01407v1)

用 20 个完全留出物体的 200 张照片，固定另一物体的配对。图像条件来自真照片，逐组件交换后重新生成。原图和供体分别对应两个开放评分词。

| 真照片条件，每组 200 张 | 画对原图主体 | 画对供体主体 | 找到原照 | 同物体十图找回原照 |
| --- | ---: | ---: | ---: | ---: |
| 原图均值与原图 token 差异 | 105 | 0 | 107 | 125 |
| 原图均值与供体 token 差异 | 0 | 77 | 1 | 31 |
| 供体均值与原图 token 差异 | 70 | 0 | 75 | 99 |
| 供体均值与供体 token 差异 | 0 | 106 | 0 | 19 |

保留原图 token 差异的命中率比只保留原图均值高 35.00 个百分点，按整个物体重采样的 95% 配对区间为 [24.00, 46.00]。固定图中，保留原图差异时顶针仍可认出，换均值使背景带上了供体碎木屑。换成供体的 token 差异，原图的画笔变成了供体的华夫饼。这项操作使用真照片，诊断生成器在两条输入路径上的响应。

## 在生成前读取实际 EEG

用注册训练照片拟合固定的线性映射，从原生融合向量及两种 token 分量预测独立 DINOv2 表征。评分库包含 1,323 个训练物体原型与 20 个留出物体原型。留出物体的正原型对每条查询排除那张照片。映射只使用训练照片，对照组输入真图视觉条件，EEG 组输入两个人对相同 200 张留出照片的真实 R4。

| 条件的来源 | 融合向量 | token 均值 | token 差异 | 完整 token |
| --- | ---: | ---: | ---: | ---: |
| 真照片，可识别物体 / 200 | 142 | 141 | 129 | 133 |
| 原生 EEG，可识别物体 / 400 | 4 | 7 | 9 | 9 |

真图的 token 均值有可以线性读出的物体信息。冻结生成器在交换对照中主要随 token 差异画主体。实际 EEG 条件的误差在进入生成器之前已经很大。两位被试的 token 差异相对训练均值的 RMS 范数分别为 26.45 和 26.19，真图相应值为 13.13。

## 只修正 token 差异

使用四名源被试的 52,920 条整类留出训练预测，学习由原生融合向量到视觉 token 差异的岭回归。原照组用当前训练照片的 $R_i$ 作为目标。物体组用同物体其余九张照片的 $R$ 均值作为目标。两组固定训练数据、输入和正则，在输出中把岭回归方向和原生偏移各保留一半。

令 $R_e$ 为当前 EEG 投影的 token 差异，$\mu_E$ 和 $\mu_V$ 分别为折外 EEG 条件和真照片条件的训练均值，$f$ 为折外 EEG 的融合条件，$B$ 为训练得到的映射。修正计算为

$$
\hat R=\mu_V+\frac {g}{2}\left[(R_e-\mu_E)
+\|R_e-\mu_E\|_F\operatorname{unit}\left(B(f-\bar f)\right)\right].
$$

原生 EEG 的 token 均值直接进入生成器。均值平移对照取 $R_e-\mu_E+\mu_V$。训练方差校准组用视觉分量和折外预测分量的训练 RMS 比为 $g$。仅平移的版本得到 0.50324，原照方向版本得到 0.56448。错配对照只换相对分量，保留查询 EEG 的 token 均值与种子。

| --- | ---: | ---: | ---: | ---: |
| Brain-HiVE | 5 | 10 | 79 | .26949 |
| 只平移 token 差异的训练中心 | 3 | 16 | 88 | .28711 |

原照加幅度校准，两位被试相对 Brain-HiVE 分别是 5 对 5，以及 3 对 0。平均差为 +0.75 个百分点，95% 配对区间 [−1.00, +3.00]。相对只校准幅度的对照，差为 +1.00，区间 [−1.00, +3.50]。相对同模型的错配对照，差为 +2.00，区间 [0.00, +5.00]。该版本的同类原照识别比原生少四张。

逐图评分共有九项改变，其中六项增加、三项丢失。九组均导出对照图并按原图核对。新增的部分骰子命中在图里仍是圆形筹码或带符号的按键。水蛭案例的细长轮廓更接近原照，背景和姿态仍不同。命名差统计保留固定评估器的原判定。

## EEG 中的照片轮廓

用训练照片的固定前景分割，学习从同一人的四次 EEG 均值预测 20×20 的软轮廓。在两人各 200 张留出的开发照上，固定训练轮廓均值的软 IoU 为 .30492，实际 EEG 为 .32270。同一模型换成同物体另一张照片的 EEG 得 .31198。正确 EEG 对错配的差为 .01073，95% 配对区间 [.00565, .01570]。

把前景平移到中心并按尺寸归一化后，三个分数分别为 .43762、.45231 与 .44599。正确 EEG 对同物体错配的差为 .00632，区间 [.00193, .01085]。这项诊断表明实际四次 EEG 含一部分与照片对应的轮廓信息，成图对照中的方法使用上面经过校准的相对 token。
