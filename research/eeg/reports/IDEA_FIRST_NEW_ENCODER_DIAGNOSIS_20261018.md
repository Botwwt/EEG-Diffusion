# 当前编码器的真实诊断结果

本报告使用新训练的十被试 ATMS max100/patience50 检查点和实际条件缓存。数据为真实 R4、63×250 输入。全部 T 132,300 query 和 V 16,600 query 均已核对；未读取官方测试或独立 H，没有新增训练。

| 原生特征诊断，十被试等权平均 | T | V |
|---|---:|---:|
| 固定真实图 gallery 大小 | 13,230 | 1,660 |
| 正确刺激 Top1 | 0.5163% | 1.3193% |
| 正确刺激 Top5 | 1.8541% | 4.4217% |
| 正确概念 Top1 | 2.1935% | 5.9398% |
| 原生特征 gallery 2AFC | 0.770350 | 0.717643 |
| 相对仅用 T 均值预测器的 MSE 降幅 | 6.8172% | 2.9127% |
| 以 T 均值中心化后的正确目标余弦 | 0.262985 | 0.207484 |
| 预测/真实特征的方差迹比例 | 0.119505 | 0.116338 |

T 与 V 的 gallery 大小不同，不能用这两列 Top1 的大小直接判断泛化差距。这些指标衡量原生 CLIP 条件信息，不能当作图片正确率。相对均值预测器的误差改善以及中心化余弦说明有可用信号；幅度收缩与弱刺激检索还不能区分优化目标、模型容量、监督方式和 EEG 信息限制。

与历史 patience20 版本比较，新版本 V Top1 从1.2108%变成1.3193%，Top5从4.4639%变成4.4217%，相对均值 MSE 降幅从2.9245%变成2.9127%。这次对齐没有显示出明显的原生条件改善。两次同 seed 训练仍有数值差异，因此这不是只改变 patience 的严格确定性因果实验；旧图片也不能充当新检查点的图片。

## 已定位的训练指标取舍

核对实际官方 `_compute_loss` 与执行代码：训练损失为 `9*MSE + 1*CLIP`，V 检查点选择损失为 `9.9*MSE + 0.1*CLIP`。下面只比较已选检查点和各被试固定的最后一轮，没有搜索检索分数最高的轮次，也没有更换检查点。

| 十被试 V 日志等权平均 | 已选检查点 | 固定最后一轮 |
|---|---:|---:|
| 选择损失 | 3.279182 | 3.481027 |
| 原生 MSE | 0.291307 | 0.314539 |
| 原生余弦 | 0.626632 | 0.588683 |
| 正确刺激 Top1 | 1.3193% | 2.3072% |
| 正确概念 Top1 | 5.9398% | 9.4819% |

已证实：后续训练的检索和 MSE 指标走向不同，现行选择规则确实偏好更低 MSE 的早期检查点。因此“再训练更久就会自动改善当前部署条件”没有得到这些日志的支持。最后一轮没有实际图片对照，其检索更高也不证明生成更好；本轮保持原先规则和固定 h，不通过回看 V 改选模型。

容量不足仍未证实：本次所有新教师都使用同一个3,200,413参数官方 ATMS 类，没有受控扩容结果。当前正在执行的最小机制检验固定这些 h，在同一预训练原生投影器、图像主干、更新数和推理成本下比较真实配对适配、普通噪声和 Conditional 的实际图片。完成固定训练 pass 本身也不证明适配器已经收敛。
