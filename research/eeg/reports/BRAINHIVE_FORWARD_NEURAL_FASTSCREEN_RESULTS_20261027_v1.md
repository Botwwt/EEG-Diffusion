# D06 前向神经测量快筛：前向门槛通过，主图像效能未通过

**决策：停止本次固定 D06 实例，不晋级，不追加 alpha、PCA rank 或 ridge 扫描。** 全部拟合、出图、DINO 与 CPU 补评已闭合；正确神经证据的全局 DINO2AFC 比原生低 **0.00696203**，也比同概念错排证据低 **0.00126582**。这同时违反原登记的相对原生至少 +0.01、相对错排大于零两项要求。目标余弦、少量同概念检索及低层对应存在正向线索，按原登记保留这些结果，不能据此改变主门槛或宣布方法胜出。[科学登记](../audit/forward_neural_fastscreen_20261027_v1/scientific_preregistration.json)、[实际 DINO](../audit/forward_neural_fastscreen_20261027_v1/actual_score_summary.json)、[完整 CPU 补评](../audit/forward_neural_fastscreen_20261027_v1/actual_CPU_supplement_summary.json)

本次是完整 T 的 13,230 个刺激、1,323 个概念、两个概念折的前向测量拟合，以及 sub-01 已曝光的 8 概念 × 10 刺激开发图片面板。图像分母为三臂各 80 张，共 240 条；其中原生 80 张复用既有不可变产物，两候选新生成 160 张，另有一张新零更新像素回放。每图仍为原生 512×512、4 次 UNet、CFG=0、IP scale=1、每 query 一图；新 UNet 调用共 644 次。没有完整 V、十被试图像确认或 SOTA 结论。[出图闭合回执](../audit/forward_neural_fastscreen_20261027_v1/actual_images_completion.json)

本次保持原始正确 BrainMLP 条件 c、A/P/IP/UNet 及 query 噪声不变。新增部分先用 outer-fit 的真实 VAE latent 拟合 PCA128 与固定 ridge0.1，预测 D04 已冻结的 group-A16 共享神经坐标，再导出原始 scaled-latent 坐标中的仿射算子 H、b。推理的额外证据是 sub-01 EEG 预测出的 Ahat，不是实际 query 的其他被试 EEG。每个原生 Euler 步在 x0 上执行：

```text
K = solve(H.T @ H + [0.1 * trace(H.T @ H) / 16] * I, H.T)
x0_flat += 0.25 * (Ahat - (x0_flat @ H + b)) @ K
epsilon_new = (sample - x0_new) / sigma，恢复原 epsilon dtype
```

正确臂使用对应 query 的 Ahat；错排臂只在同被试、同折、同概念的十项内固定循环错排 Ahat，仍保留正确 c。两候选逐 query 核对相同初始噪声、首个 UNet 输入和四次实际祖先噪声；正更新出图前要求新零更新图片与缓存原生图片逐像素相同。alpha=0.25 是更新系数，不是扰动范数上限。该过程是依赖训练拟合算子的有限修正启发式，不能解释为物理测量、精确后验或独立噪声融合。[生成源码](../generate_BrainHIVE_forward_neural_fastscreen_20261027_v1.py)
