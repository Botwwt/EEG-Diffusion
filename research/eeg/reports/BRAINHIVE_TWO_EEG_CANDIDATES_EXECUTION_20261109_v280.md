# EEG 配对能量与空间残差的完整比较

本轮在重建的 sub-03 Brain-HIVE 上验证两条 EEG 编码端假设，保留 historical ordinary。2026-11-09 08:29 UTC 的实际观察显示，普通训练对照和正确配对方案均已完成全部 827 次更新、13,230 条 T，并通过独立断点检查；反向配对对照正在训练。**尚无本轮真实图片收益，不能据这些训练终态宣布第二项方法成功或 SOTA。**

固定研究范围为单被试、物理平均四次重复的 R4、单 seed 1729。六组完成后比较全部 830 条 Dcheck、14 组、每 query 一张图；正常条件只由该 query 的 EEG 产生。

## 1. 为什么改变训练目标和输入位置

旧实验多次出现“整体余弦或 MSE 改善，但同概念刺激区分、图片语义未改善”。新匹配 ordinary 的第 512 次更新也出现匹配余弦 0.105840→0.183543、同概念 Top-1 31.6478%→31.3152%。这些是 T 上的训练诊断，不能代替图片结果，却说明平均接近视觉教师与保留刺激差异需要分别测量。

本轮同时检验两个不同问题：现有 EEG 编码器能否学到生成器实际使用的刺激差异；原来未使用的电极能否补充原 17 个电极之外的预测信息。两条线都有匹配对照，不继续扫描旧的半径、强度或中间 epoch。

## 2. 配对能量目标

令 E 为 EEG 编码器，G 为冻结的原生 A/P/IP/UNet。对同一真实 T latent、噪声和时刻，定义正确 EEG 与同概念另一刺激 EEG 的误差：

$$\ell_i^+=\operatorname{mean}\|G(z_t,t,E(e_i))-\epsilon\|^2,\qquad
\ell_i^-=\operatorname{mean}\|G(z_t,t,E(e_{j(i)}))-\epsilon\|^2.$$

训练目标为：

$$L_A=\operatorname{mean}\ell_i^+
+\tau\operatorname{mean}\operatorname{softplus}((\ell_i^+-\ell_i^-)/\tau)
+0.1L_{\mathrm{token}}.$$

负例是同概念的不同刺激，以免只靠粗概念分离完成任务。若误差含一个与 EEG 无关的加性项，它在差值中精确抵消；这不等于消除所有公共特征，也不把单时刻 MSE 冒称为精确后验对数比。

τ 在新拟合前，用固定 64 个 T 概念的 256 条 query，按原生配对误差差值的 RMS 一次确定，最低 1e-4；所有 A 组共享。直接训练原生编码器已有的 6,450,176 个参数，固定输出 LayerNorm affine；学习率 1e-5。该阶段关闭编码器 dropout，原 25 轮父编码器的随机教师训练不改。

| 组别 | 改动 | 要回答的问题 |
|---|---|---|
| A_positive | 相同双分支计算图，对比项权重为零 | 普通生成器监督本身能改善多少 |
| A_pair | 正确配对的能量差 | 配对刺激差异是否有额外收益 |
| A_reverse | 正确正例锚不变，只反转对比项符号 | 收益是否依赖正确的能量排序 |

去噪能量判别和对比扩散有明确近邻，包括 [Diffusion Classifier](https://openaccess.thecvf.com/content/ICCV2023/html/Li_Your_Diffusion_Model_is_Secretly_a_Zero-Shot_Classifier_ICCV_2023_paper.html) 与 [CMMD 第 2.2 节](https://www.microsoft.com/en-us/research/uploads/prod/2024/10/ECCV_2024_avgenl.pdf)。公式本身不作为原创结论。需要实际 EEG 配对机制、图片和强对照支持，才能讨论贡献。

## 3. 原生输入投影的空间残差

记原 17 个后部电极为 eP，另 46 个电极为 eN。只用 T 的 EEG 估计每电极、时间点均值，以及在 T 和时间轴上汇总的空间协方差：

$$B=C_{NP}(C_{PP}+\lambda I)^{-1},\qquad
\lambda=10^{-3}\operatorname{tr}(C_{PP})/17,$$

$$r=(e_N-\mu_N)-B(e_P-\mu_P).$$

在原生第一投影处更新：

$$h=W_{\mathrm{old}}e_P+b_{\mathrm{old}}+U\operatorname{vec}(r).$$

U 为 11,500→1,024 的无 bias 投影，11,776,000 参数，零初始化；原 17 电极投影、残差 MLP 和输出 affine 全冻结。三组都只训练 U，学习率 1e-4，使用原正向噪声 MSE+0.1 token 目标。

| 组别 | 输入 U 的量 | 要回答的问题 |
|---|---|---|
| B_residual | 正确 query 的条件空间残差 | 条件化后是否更有用 |
| B_raw | 相同均值中心化，B=0 | 是否只是多电极、多参数的作用 |
| B_shuffle | 训练时用同概念另一刺激的残差 | 是否依赖刺激配对 |

B_shuffle 的正常推理仍只使用当前 query 自己的 63 电极 EEG；错配映射仅用于 T 训练控制。

这个投影可折回原生线性层：

$$W_N=U,\quad W_P=W_{\mathrm{old}}-U(B\otimes I_{250}),\quad
b=b_{\mathrm{old}}-U\operatorname{vec}(\mu_N-B\mu_P).$$

真实训练后权重的 GPU 和独立 CPU FP64 代数检查已通过；当前推理仍使用分解形式，没有完整图片相等或端到端加速主张。Ridge 正规方程给出的是正则化后的交叉协方差关系，不证明 r 与 eP 独立，更不等于生理噪声或脑源定位。B 使用更多电极和更大容量，后续竞争性结论还需要强 63 电极基线。

## 4. ordinary 和组合的权限

旧 ordinary 的权重和历史结果保留。另在新父模型的真实 T 折外条件上拟合了匹配 sub-03 ordinary：原 525,568 参数头、半径 0.25、3 遍 T、2,481 更新、39,690 暴露。最后断点和完整覆盖已独立检查。

GPU 5098166 在原 Dfit 的 820 条、82 个概念上，只按固定五强度 0、0.25、0.5、0.75、1 校准，选择 1。最终组件 SHA 为 `f6998db9a49d566547bfbca045d47d471c771d4d0c6880322fbd9067d7024f99`。这是匹配基线重建，不是新的图片收益。

14 组为原生、匹配 ordinary、六个新编码器各自不搭配/搭配这个冻结 ordinary。组合是明确的分布变化与交互测试，不能称为针对每个新编码器重新训练的 matching ordinary，也不能预设收益相加。新编码器与 ordinary 可分别关闭，不代表统计独立或已有第三项创新。

## 5. 实际训练与完整图片流程

六组均固定最后检查点：一遍完整 T、13,230 query、batch16、末批14、827 更新、单 seed1729。GPU 5098229 各完成首两次真实更新，CPU 5098276 独立检查模型、Adam、RNG 结构、覆盖、冻结参数和空间折叠代数。首两次计入总数，接续不重训。

正式链由 5098317 启动，每段有限20分钟、1000秒附近安全保存，并在独立 CPU 断点检查后接续。已闭合的 A_positive、A_pair 均完整 827/13230；它们的模型 SHA 分别为 `3a81b2c97cf03d614d842a3bd265dda0dba4c968f3c55b9a779c9f43781f2f5a`、`4a57d00835dd3f1b4db112497703521ca42c27bdeb46bd2a9d74a2abc13ce3af`。

完整训练后，CPU 独立重放 830 条 EEG×7 个编码器，再构建 14 组条件。随后生成 11,620 张原生512×512、4步、CFG0、IP1图片。每 query 跨方法共享初始噪声和采样随机流；保存条件、图像字节/像素和随机状态 SHA。第一条原生路径还必须重放原 pipeline 像素及最终随机状态。

图片调度器已改为读取封存阶段回执，避免下一分段覆盖 progress.json 的竞态；只撤了未分配资源的旧 CPU 等待任务，训练数值源、权重、RNG 和 GPU 作业不变。

固定输出包括 DINO 全图库和同概念检索、论文七项 PixCorr/SSIM/Alex2/Alex5/Inception/CLIP-L14/SwAV，以及 EffNet。完整相似度矩阵保存，终态 CPU 重算全部排名和配对差；83概念×1000次描述性 bootstrap 不代表训练 seed 或被试稳定性。ObjectF1、CapSim 及完整 SEED 尚未恢复，缺项保持明确，不能据此宣布原完整门槛通过。

全部指标共同解释变化，没有按单项淘汰或选择 epoch 的自动分支。正向结果还须超过匹配对照与强原生/ordinary，并继续更广被试和官方同权限比较；当前是已曝光开发划分的一次单被试研究。

## 7. 完整 T 的训练诊断

CPU5098809在两组固定最后827更新后，对完整13,230条T做同概念十图诊断，并对每个模型的固定四条实际EEG独立重放，17秒闭合。这里比较的是 full-T 原生编码器与同样看过 T 的新模型，**不是 OOF、验证集或实际图片效果**。

| T 指标 | 原生 full-T | A_positive | A_pair |
|---|---:|---:|---:|
| 正确 F 余弦 | 0.342260 | 0.371407 | 0.375098 |
| 同概念最难负例余弦 | 0.216969 | 0.347386 | 0.342428 |
| 正确减最难负例间隔 | 0.125291 | 0.024021 | 0.032670 |
| 同概念 Top-1 | 99.3802% | 77.6342% | 82.8949% |
| F-MSE | 1.316440 | 1.260957 | 1.253906 |

正确配对相对普通训练净多判对696条：797条由错变对、101条由对变错。Top-1差+5.2608个百分点，T概念重采样的描述性95%区间为[+4.7691,+5.7447]个百分点。

这支持“相同训练预算下，配对项减轻了刺激区分损失”的训练线索。普通训练中，最难负例余弦的增长明显大于正确余弦增长；配对项使负例余弦相对普通组下降0.004958，同时正确余弦增加0.003691，因此间隔回升0.008649。但两组仍低于原生的训练内区分，不能据相对弱化后的对照宣布编码器全面更强。

同一T顺序和query暴露下，整个训练轨迹的正向噪声误差均值为A_positive 0.166838、A_pair 0.168131；成对误差间隔均值分别0.000673、0.000825。它们来自不断更新的模型，不是最后模型的冻结验证。较大的正向误差与较好的配对区分可以并存，故不会只按这一个loss淘汰方案或据此修改已登记训练。下一结论仍由完整留出图片和反向配对对照决定。
