# 论文生成链路复现与组件移植审计

先完成作者公开生成链路的复现，再检验组件增量。现有 ATMS 直接条件加 SDXL Base 的实验属于受控机制研究，不能标作 ATM 论文完整复现。目前新完成的是源码、预训练权重和 CPU 接口检查，尚无这两条新复现链路的图片结果。

## 复现对象

| 对象 | 作者公开生成路径 | 当前证据 | 必须补齐的条件 |
| --- | --- | --- | --- |
| ATM 语义支路 | ATMS EEG 特征 → DiffusionPriorUNet → CLIP H 条件 → IP Adapter → SDXL Turbo | 固定 main 提交 `49cb3a20a0c1fd35fd2955f78d0e4d0f2939c70d`；十被试作者 prior 全部严格加载，参数各 9,675,648；公开测试 EEG 特征均为 200×1024；生成模块 CPU 导入通过 | 实际生成、逐图配对和评价；公开 EEG 特征的上游编码器权重与逐行身份仍不完整，不能据此宣称端到端 EEG 复现 |
| ENIGMA | EEG 网络 → CLIP H 条件 → IP Adapter → SDXL Turbo，无 diffusion prior | 固定作者提交 `460af4b6a0ca6eee11aeaf35c5431e8e3d55c11a`；原网络类 CPU 前向通过；单被试 1,405,242 参数、十被试共享网络 1,969,992 参数 | 作者环境与数据格式、预处理元数据、完整训练和图片评价；论文与当前代码有结构差异，需要分开注明 |
| DreamDiffusion | EEG 编码与 Stable Diffusion 条件生成 | 已查作者仓库的生成流程与依赖 | 原方案的数据规格不同。移植到现有 THINGS EEG 应记为同数据移植基线，不能算原论文复现 |

ATM 作者的[复现说明](https://github.com/ncclab-sustech/EEG_Image_decode/tree/49cb3a20a0c1fd35fd2955f78d0e4d0f2939c70d)区分语义、低层结构和字幕分支。此轮先对齐语义支路，不把三个分支混为同一设置。该 notebook 用 prior 50 步、CFG 5，图像生成器用 Turbo 4 步、CFG 0、IP scale 1；作者 notebook 生成十张，用户要求覆盖为固定 seed 每 query 一张。当前 main 的可用历史经过清理，不能当作已找回的 2024 原始提交。

[ENIGMA 作者实现](https://github.com/Alljoined/ENIGMA/tree/460af4b6a0ca6eee11aeaf35c5431e8e3d55c11a)与[论文第 3.3 节](https://arxiv.org/html/2602.10361v1#S3.SS3)存在明确差别：代码在 CNN 前做 250 维时间映射、卷积使用 ELU；论文描述 CNN 后的 184 维 latent alignment 和 GELU。原代码结果与按论文重建的结构须分别记录，不能悄悄替换后称严格一致。论文标题中的十五分钟指校准数据时长，不能用作训练耗时预算。

## 已运行的检查

作者 ATM 数据仓库固定于 `dbe34bb2407164f70883c661c76664f0d596e522`。20 个 prior 和测试特征资产共 395,546,430 字节，逐文件核对公开 LFS SHA256 和服务器实际 SHA256，直接通过内存传至服务器。C/D 未保存这些资产。该公开清单 71 个文件中没有 EEG 编码器检查点；prior 参数文件也没有可证明训练更新次数的优化器记录。

作者十被试测试 EEG 特征的平均范数为 5.91 至 9.20；本次已审计的当前 R4 条件总体平均范数约为 14.07。两者的训练集与重复数不同，不能据此比较能力高低；但不能仅凭同为 1024 维，就把作者 prior 接到当前编码器上并当作原始复现。解码复现应先使用作者匹配的特征和 prior。作者 prior 的默认 DDPM 调度器开启 `clip_sample`，当前受控链路曾关闭它；复现需保留作者设置并记录差异。

ENIGMA 的完整模型模块在现有环境首次导入缺少 `open_clip`。保留了失败回执；随后执行未经修改的原网络类体，验证了 63×250 输入到 1024 输出的尺寸、有限值和参数量。这不等于作者完整环境已经运行成功。

ENIGMA 固定版本 `evaluate_recons.py` 的 `two_way_identification` 在严格小于比较后又减一。CPU 数学自检中，200 个正确配对原始特征得到 0.9949748744，正确严格比较为 1；固定循环打乱同样相差 −1/199。这是已验证的脚本问题，尚不能断言论文最终表格使用了该函数。保留作者计算结果，另报统一评价口径，不改写既有实验分数。

当前登记的训练 EEG 是四次物理重复的均值。均值无法还原四条独立 trial，不能复制四份冒充作者的单 trial 训练输入。现有完整图片机制实验仍按原登记 R4、全部十被试、16,600 query 收尾。

## 组件的边界

候选方向是生成条件接口上的 EEG 误差校准。先保留父模型的编码器、先验与生成器，再在父模型输出的原生生成条件位置接入组件。ATM 对应 prior 输出，ENIGMA 对应 EEG 网络输出；其维度相同不代表误差分布相同。

这只是待验证的组件设计，尚未实现新训练分支。每条父链路都需要自己的条件统计与可训练权重。关闭组件应恢复原始链路；不得为适配新方法改变父模型归一化、采样器或评价标准。旧 q-v2 未通过绝对条件分布检查，不能直接作为可迁移组件带入。

每个已复现父模型均比较原始模型、相同参数量的普通适配器、我们的组件，并保留正确、打乱与缺失 EEG 条件的诊断。同一比较固定训练数据、允许信息、seed、每 query 图片数和采样成本；判定依赖完整图片与逐 query 指标。

ATM 和 ENIGMA 可首先检验不同 EEG 映射链路上的迁移性，但二者都使用 SDXL Turbo 与 IP Adapter。即使两者通过，也只能声称这一范围内可迁移；跨生成器架构还需第三个实际验证的家族。
