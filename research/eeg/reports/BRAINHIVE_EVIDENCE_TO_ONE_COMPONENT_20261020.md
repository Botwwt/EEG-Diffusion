# 从既有实验收敛到 Brain-HIVE 的一个组件

执行顺序固定：完成 Brain-HIVE 原生 EEG→图片复现及评价，然后冻结父模型，只验证一个适配组件。原生八项评价是这次复现的收尾，不增加第二架构、更多训练 seed 或更多生成候选。当前组件没有训练，也没有图片增益结论。

| 已有实际证据 | 支持的判断 | 对下一步的约束 |
|---|---|---|
| 旧 A1/A2/C1 等小范围图像修正未建立优势；B1/B2 有前置依赖缺失 | 这些具体实现不成功或不可判定，不能据此否定整个研究问题 | 不直接叠加失败分支；不把缺少实验记为负结果 |
| 旧紫色图随残差关闭而消失，VAE/保存数值检查通过 | 修正分支可破坏生成；并非已证实保存流程故障 | 新分支零初始化，关闭时精确恢复父模型，修正有界 |
| ATMS/Base512、十被试全量 R4：Frozen DINO 0.758269；RealPaired 0.720041；Conditional 0.724959 | 两种既有投影器微调都损害主要图片指标 | 冻结 Brain-HIVE 原生 A/P/IP；原模型和普通适配器同时作匹配参照 |
| Conditional 的部分误差结构/UNet响应诊断较好，图片 ObjectF1 仍低于 Frozen | 生成器对条件误差的响应值得研究，但中间诊断不足以证明图片成功 | 必须经过实际生成、逐 query 指标及质量检查，不能止于语义向量或响应损失 |
| q-v2 真实/模拟分布强分类器 AUC 0.99984，且偏离真实 LayerNorm 支持集 | 现有条件模拟器不能作为已验证的真实 EEG 误差替身 | 使用已完成的真实概念 OOF 条件；不移植 q-v2 合成器 |
| Brain-HIVE 完整 T-OOF 原始配对余弦 0.107636，固定打乱 0.001112；Dcheck 为 0.128912/0.003041 | EEG 有配对相关信息；不是没有信号 | 检验如何保留和利用这些信息；图像增益仍须由已登记正确/打乱/缺失组判断 |
| Brain-HIVE Dcheck token 配对余弦 0.587551，打乱也有 0.520087 | 大量公共成分使总余弦看起来较高 | 不把总余弦当成对象正确；修正应关注刺激相关方向，并以图片作判断 |
| 仅 Dfit 拟合 A 输出幅度后，Dcheck token 余弦略降；修正前后自身余弦 0.999977 | P 的 LayerNorm 基本消除了该全局幅度修正 | 不先投入全量的单纯放大实验；不等同于否定所有注意力强度调整 |
| Brain-HIVE 固定 32 张真实图像条件诊断可恢复多种对应对象，也有失败例 | 原生生成接口有操作能力，存在生成器上限 | 不把 oracle 当正常方法、不能额外读取测试目标 |
| 拟合内条件比真实 OOF 更接近视觉目标 | 泛化差异存在 | 不能凭此断言模型太小；没有容量受控对照，暂不扩容 |

第一个待验证机制是**有界条件方向修正，以及可独立检验的预测风险校准**。它接在冻结 EEG 输出与原生 A/P 之间；保留原生坐标、实际维度和所有预训练权重。修正从零初始化，必须测出修正前后 token 与实际 UNet 响应的变化，排除分支未加载或被归一化抵消。预测风险表示对视觉条件的预测误差，不能称作生理 SNR。

在完整允许 T 的 132,300 条真实折外 subject-query 上训练；只用 Dfit 做风险校准，Dcheck 单次检查校准及折外到完整父模型的分布变化。正常推理只读 EEG 条件。具体网络、训练目标、固定更新数和修正界限将在有限的工程 profiling 后、任何候选图片评分前锁定；本文件不是已执行训练或超参数登记回执。

必要比较是原生父模型、同数据/容量/更新的普通受限适配器、风险校准组件。风险打乱或固定门控用于判别风险信息是否有独立价值，不能只证明“加了参数有效”。正式比较使用保护划分 R4；完整 V 每组 16,600 个 query、相同噪声、一图/query、同四步 Turbo，不与原生 R80/200-gallery 跨协议排名。沿用既定 DINO +0.01 实用门槛、独立语义与质量要求；失败或不确定时保留结果，不靠反复查看官方测试集调参。

训练准备只绑定已有真实条件和目标缓存，不复制大张量。元数据入口为 `prepare_BrainHIVE_component_input_contract_CPU_v1.py`，服务器输出 `data/component_input_contract_v1.json`。它核验全部 T 恰好一次 OOF 覆盖、概念排除、父检查点与缓存 SHA，并严格分开 Dfit/Dcheck；文件存在不等于组件已训练。

生成阶段路由和 KAN 留作简化组件有证据后的受控消融。只在一个已复现父模型上成功时，只能声称适用于该父模型；通用于所有 EEG diffusion 架构仍是后续目标。

完整生命周期的持久存储必须在训练前预留，C/D 不保存大权重或图片。已回收的旧派生缓存有逐字节恢复证明；原 EEG、唯一训练权重和历史原图保留。不得先训练出无法完成图片评价的版本。
