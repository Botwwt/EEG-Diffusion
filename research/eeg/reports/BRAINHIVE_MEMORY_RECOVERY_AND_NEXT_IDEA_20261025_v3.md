## 3. 四臂结果应怎样读

完整数值与配对区间见[四臂最终报告](BRAINHIVE_FOUR_ARM_FINAL_EFFECTS_AND_ANALYSIS_20261025.md)。以下是事后解释，不能倒过来改写原主门槛。

### 3.1 增加功能损失没有改善普通 O 的目标区分

PN−O 的 DINO2AFC 为 **−0.000333**，SEED 为 **+0.000829**，两项区间跨零。PN−P 虽有微小正向增量，但 PN−S 的 DINO、SEED 区间仍跨零，不能用前一个对照省略后两个。排序教师的配对机制没有得到完整支持。

更值得定位的是：PN−O 的 **DINO 总余弦 +0.004091**，同时 DINO2AFC 并未改善。P−O 也表现为总余弦 **+0.003507**、DINO2AFC **−0.001886**。这说明“更接近正确图的特征”和“更能把正确图与其他候选区分开”在当前结果中没有同步改善。

它与公共相似度偏移的解释相容，但不是公共成分、hubness 或某个注意力层导致失败的证明。只有控制正确与错配 EEG 的功能差，才能进一步判断。

### 3.2 三个功能分支有相近的低层代价

P、PN、S 的 SSIM_Y 约 **0.23994、0.24068、0.24002**，普通 O 为 **0.26674**。P−O 的 SSIM 差为 −0.026806，PN−O 为 −0.026063；两者描述性区间均全负。PN−O 的像素相关差 **−0.004764**、平均 RGB 绝对误差差 **+0.006473**也指向低层重建不利。

这个模式更值得先检查功能正教师项共同引入的偏移、训练状态与采样状态关系，以及实际基础/辅助梯度竞争，不能只归因于排序负例不够难。它仍不等同于人类感知质量下降，尚无人工非劣实验。

### 3.3 优化器确实优化了代理目标

固定首尾日志窗口中，P/PN/S 的辅助项分别下降约 **0.12151、0.11627、0.12246**，日志值有限，未触发极端增长规则。这排除了“完全没有优化辅助目标”的简单解释，不能证明代理对生成语义有用。

因此继续加 epoch、扩大辅助权重或把 rank 换一个名称，尚无针对性依据。

## 4. 中间层结果不支持什么，又没有排除什么

c+h0 相对重复 c 的 MSE 改善在两个 λ 下仅 **0.1576% / 0.1408%**，余弦间隔增量为 **+0.000189 / −0.000120**。λ=0.1 时有8/10被试两项同向，λ=1.0 时仅1/10；正则变化后刺激区分方向不稳。

因此应暂缓“直接融合当前 BrainMLP 中间层”“加一个归一化前统计旁路”“没有证据就换 KAN”这类新训练。这里测的是 **EEG 编码器内部层对冻结 F 的固定读出**，没有检验视觉教师的最佳可解码层，更没有排除视觉目标本身的可预测性问题。

## 5. 当前最值得检验的 idea：以配对效应为目标，限制公共响应漂移

这是一项**待功能诊断支持的候选假设**，尚未注册正式训练，更没有创新性或收益结论。它的具体问题是：当前损失可能主要降低教师公共响应误差，却没有增加 EEG 对刺激身份的可控效应，还付出低层重建代价。

令在同一参考状态、同一停止梯度 Q 下的原生 IP 响应为

$$R_Q(c)=\operatorname{SDPA}(Q,K_{IP}(P(A(c))),V_{IP}(P(A(c)))).$$

对同被试、同 OOF 编码器角色、异概念的 T 配对 i、j，定义学生与教师的差分：

$$\delta_s=R_Q(C_\phi(c_i))-R_Q(C_\phi(c_j)),\qquad
\delta_t=\operatorname{sg}[R_Q(F(I_i))-R_Q(F(I_j))].$$

待检验目标可写为

$$L_{pair}=\frac{\operatorname{mean}[(\delta_s-\delta_t)^2]}
{\operatorname{sg}[\operatorname{mean}(\delta_t^2)]+\epsilon},$$

其中退化教师仍须按事先规则屏蔽并保持完整分母记录。**相同 Q 和两个经过同一头的 EEG 分支必不可少**；不能把不同 query 自己的 Q 差异误当成条件效应。

差分能消去严格相同的加性公共项，但非线性注意力下不能保证消除一切共模影响。它也可能鼓励不合理的相对方向或放大不可从 EEG 恢复的教师细节，因此不是直接替换成这个 loss 就算改进。

与只奖赏正负距离差的排序项相比，该平方差在响应差分空间对过度外推也会惩罚：若δs=αδt，损失随(α−1)²变化。它仍可能拟合EEG不可恢复的教师细节，不保证最终图片正确。

已实现一个[仅数学原型的DRAFT函数](../brainhive_paired_effect_DRAFT_20261025_v1.py)及[CPU代数检查](../check_BrainHIVE_paired_effect_DRAFT_CPU_20261025_v1.py)：共同响应平移不变、交换对称、两个学生分支均有反向梯度、教师停止梯度、退化项保持全分母、过度外推被惩罚。函数没有训练入口，也无法自行证明同Q、OOF身份和输入权限；这些真实集成尚未完成，不能写成候选工程或效果已通过。

若真实梯度分析支持竞争，可进一步检验基础目标约束，而不是盲目调大权重。设

$$g_b=\nabla_\phi(L_\epsilon+0.1L_{token}),\qquad g_a=\nabla_\phi L_{pair}.$$

一项局部一阶约束是，在两者冲突时去掉辅助梯度反对基础目标的分量：

$$\tilde g_a=g_a-
\frac{\min(\langle g_a,g_b\rangle,0)}{\|g_b\|^2+\epsilon}g_b.$$

这只是待比较的常见梯度约束形式，不是创新本身；AdamW 预条件、有限步长、真实采样轨迹和最终像素均不由该一阶式保证。与普通 pair/relational distillation、常规梯度处理的差异与增量需要真实对照。

**注册边界**：原方案要求教师已知噪声对照一致支持，当前仍未满足，不能自动放行原功能训练。追加图片探针为视觉条件的语义作用提供了另一维线索；若据此提出新的配对效应假设，必须另写正式协议，区分“视觉条件能指导语义”“EEG能预测该目标”“新损失改善生成图片”三个问题，不把新探针倒填为旧门槛通过。当前新目标仍属DRAFT，不能由开发集微小均值直接启动。

### 5.1 收敛为一个可归因的实验设计，而不是继续加模块

当前只保留一个方法假设：**绝对响应目标会允许公共移动，新增监督应直接检验同一Q下的配对条件效应。** 普通头、半径、宿主、原训练信息权限和推理四步预算均可保持；本轮没有理由把KAN、中间层旁路、动态路由、梯度投影与新目标捆绑。

若教师图片诊断给出语义作用线索，下一份正式协议仍须分别注册：计算匹配普通头、绝对响应目标、配对差分目标、打乱教师差分目标。打乱控制须保留训练教师边际分布与计算量，只破坏EEG配对；不能拿当前“只打乱排序”的S直接冒充新的差分控制。候选输入配对限定同被试/同OOF角色/异概念，两个EEG分支各用自己的真实affine，同一个停止梯度的parent-Q；不能从当前8个诊断刺激挑训练pair。

这一目标只需要额外的条件头和原生响应计算，设计上不应增加正常推理UNet次数。完整训练的计算匹配与资源仍须真实profile，不把“无额外推理步”写成“训练成本相同”。需要在新正式实验前锁定完整数据覆盖、强度/校准、固定最后检查点、图片低层代价与失败判据；未签发新训练注册，也不重置既有候选数量上限。

已有T诊断是事后定位而非新验证。未来若目标只提高这个探针、没有完整图片增量，或者不能胜过打乱教师差分控制，应直接否定该解释，不继续通过换负例、改层权重或扩大半径追逐同一个V。

## 6. 要形成 CCF A 投稿，需要怎样的证据

论文主张应围绕“什么代理失效、可测的 EEG 配对效应如何被恢复、代价如何受控”形成闭合论证。新增 MLP、负例、蒸馏或梯度投影这些名称本身不足以构成贡献。

最低限度应准备同容量普通头、仅绝对误差、配对差分、打乱配对差分及有实测依据的附加约束对照，并保持数据权限、噪声与推理成本一致。当前按既定单训练seed执行，不能从subject/concept重采样推断训练稳定性；未来若扩展多个训练seed，应另行锁定预算和方案。官方可比拟合/评价、低层与感知质量边界，以及支持通用主张的第二宿主仍属未完成工作。

最终方法与参数必须在读其新确认结果前锁定。已经曝光的开发 V 或官方200刺激不能被重新命名为未曝光独立确认集。没有某个固定的单一分数涨幅可以保证 CCF A 录用。

## 7. 相关工作对下一步设计的约束

已核对以下原始论文。它们用于界定贡献边界，不能拿各自不同任务和评价协议下的数字直接给当前方法排名。

| 工作 | 已有方法与当前候选的关系 | 对本项目的含义 |
|---|---|---|
| [Relational Knowledge Distillation，CVPR 2019](https://openaccess.thecvf.com/content_CVPR_2019/html/Park_Relational_Knowledge_Distillation_CVPR_2019_paper.html) | 已将样本间距离、角度关系作为蒸馏目标 | “不拟合单样本绝对激活、改拟合关系”本身已有先例；本项目须证明原生生成状态中的配对条件效应为什么是必要目标，并与普通关系蒸馏比较 |
| [Gradient Surgery，NeurIPS 2020](https://proceedings.neurips.cc/paper_files/paper/2020/hash/3fe78a8acf5fda99de95303940a2420c-Abstract.html) | 对冲突任务梯度作投影已有方法 | 上述一阶投影只能是已有优化手段，不能写成新贡献，也不能用梯度余弦替代图片收益 |
| [ConceptAlign，arXiv:2608.15163v1](https://arxiv.org/html/2608.15163v1) | 在 fMRI / NSD、MindEye2 框架中，用场景相近但语义错误的 caption 负例约束解码语义边界 | 不能泛称首次用反事实负例改善脑视觉重建；它并非本项目的 EEG / 原生 IP 响应差分目标，仍需精确比较 |
| [NVOL，arXiv:2609.02582v1](https://arxiv.org/html/2609.02582v1) | 使用 CLIP 视觉中间层融合、EEG 对齐、CSLS 检索及层次扩散生成 | 本轮被否定的是特定 BrainMLP 内层的固定读出，不是视觉教师中间层；若后续证据指向目标可解码性，应纳入这一直接相关路线 |

当前能形成的研究切入点是：**区分教师绝对接近、可控的 EEG 配对效应和真实采样状态下的作用，再检验哪一项可以解释并改善生成结果。** 这一问题是否足够新、是否能形成方法优势，仍须后续证据和更完整文献比较。
