## 1. 迭代慢的实际原因与采用的流程

## 2. 真正运行了什么

来源为已有sub-01训练物理重复文件，完整SHA核验后才读取。全部16540行重新求mean4，与既有训练均值缓存逐位一致；仅导出T的13230刺激、每刺激真实4次、17个原HIVE电极，形状`[13230,4,17,250]`。输入准备20.37秒，无CUDA初始化、无需新增下载。每个刺激的物理记录确实不同；没有会话身份，不能声称四次重复独立。

| 项目 | 实际设定 |
|---|---|
| 范围 | 单被试sub-01，全部1323个T概念／13230刺激，两折概念隔离 |
| mean | 先平均4次记录，再经过非线性EEG编码器 |
| each_mean | 同样4次记录分别经过共享编码器，再平均中间表征 |
| 模型 | 4250→1024 GELU/LayerNorm→1024/LayerNorm；每组5406720参数 |
| 公平性 | 同初始化、同训练次序、同参数量；each_mean有4次编码调用，计算量未匹配 |
| 拟合 | 固定25 epochs，batch256，seed1729，AdamW lr5e-4／wd.05；raw F目标MSE |
| 选择 | 固定最后epoch；没有按留出指标择模、改epoch或调超参数 |
| 输出 | 每臂13230行完整OOF预测，覆盖均恰好一次，保持拟合的raw F坐标 |
| 图片 | 事前按hash固定每折4概念，每概念全部10刺激；单被试80query×2臂=160图 |
| 宿主 | 原生冻结A/P/IP/Turbo，512×512、4步、CFG0、IP1、单图，同query实际初始噪声一致 |

正常推理不读取目标图、目标标签或逐query目标范数。全部160图完成后才读取目标像素；生成图片逐文件、像素SHA与噪声配对由评分入口复核。加载器2641个原生转换权重张量逐项一致。

这次实现只检验`phi(mean EEG)`与`mean(phi(each EEG))`，尚未实现显式时延、增益、异方差潜变量或完整生成后验。它也不是原6.45M BrainMLP／InfoNCE的复现，不能将其绝对指标直接和旧O排名。
