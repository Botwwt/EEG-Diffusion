# 当前prior目标选择：高噪声EEG作用、对比目标的边界及新增近邻

这份记录用于约束下一次研究选择，不修改正在运行的四个prior、五个新图片分支、原80→400规则或任何冻结基线。当前新图片效能尚未完成独立判读；工程通过和下面的合成计算都不是第二方法的效果。

## 1. 训练日志真正指向哪里

[完整600条日志分析](../audit/ATM_error_geometry_training_log_analysis_20261104_v1/analysis.json)显示，配对误差几何与等尺度控制最后十轮的在线clean MSE为0.192632和0.193027，只差0.000395。配对方向在t0–249更好，但后三个时间段略差；这些带噪状态均由真实T视觉目标生成，低噪声优势不能直接归因于EEG作用更强。[当前推导与协议](ATM_EEG_ERROR_GEOMETRY_PRIOR_PROTOCOL_20261104_v1.md)

当前参数化在高噪声极限有一个直接含义。令a趋近0、b趋近1，且人工噪声epsilon独立于F和c，则

```text
u -> epsilon
v_target -> -(F-m(c))/sqrt(lambda)
D -> m(c)-sqrt(lambda)*N(epsilon,t,c)
```

固定c，在该极限下最优平方误差预测满足

```text
N* = -(E[F|c]-m(c))/sqrt(lambda)
D* = E[F|c]
```

因此改变lambda并不会在无限容量下自动产生新的EEG信息。它改变有限网络的优化坐标与权重。真正需要检查的是模型在正常采样中是否更准确地兑现可从EEG预测的条件分量，而不是仅恢复低噪声状态中已经可见的真实图像信息。实际t999仍不是严格的a=0；这里是极限推导，不是对现有程序输出的精确恒等声明。

这也不要求把全部采样变为确定均值：条件分布的多模态与可预测均值是不同问题。当前没有因此挑epoch、缩短采样、增加CFG扫描或新增训练。

## 2. 为什么不能直接补一个正负去噪误差差

考虑拟议目标

```text
J(D) = (1+eta) E_P ||F-D(Z,C)||^2
       - eta E_Q ||F-D(Z,C)||^2
Q(F,Z,C) = P(F,Z) P(C)
```

这里的负条件独立抽样，不等于当前所有同概念错排规则。展开对D的二次项，在每个(z,c)处，其系数是

```text
k(z,c) = (1+eta) p(z,c) - eta p(z)p(c)
```

若某一区域k为负，而且D的输出不受约束，则扩大该处输出的范数会使目标趋向负无穷。训练目标可以变好，正确条件的重建却同时变差。这是带符号二次风险的经典性质，不是新定理，也不证明所有对比损失都会失败。

[已执行合成检验](../audit/contrastive_denoising_target_logic_20261104_v1/synthetic_risk_check.json)采用两个等概率条件C=±1、F=C、Z=F+N(0,0.4²)、eta=0.1。仅在C=-1且Z落于[0.7,1.3]时令D=-M，其余为0。按四种正负条件组合显式求和，与展开式的结果一致：

| M | 正确条件clean MSE | 上述目标J |
|---|---:|---:|
| 0 | 1.000000 | 1.000000 |
| 8 | 1.000256 | -0.093221 |
| 32 | 1.005128 | -13.866087 |
| 128 | 1.086156 | -226.355579 |

这只是合成风险反例，没有实际EEG、GPU、模型更新或研究图片。它要求未来区分“条件配对改善”和“错误分支被故意推坏”；不能只看正负margin增大。输出有界或采用softmax/softplus可改变这个反例的适用性，但损失有下界本身仍不等于后验正确或图像受益。

## 3. 本次实际核对的近邻

[MCLR第3.5节](https://arxiv.org/html/2603.22364v1#S3.SS5)已经使用正确与错误条件的去噪误差差，并明确指出ELBO替代不必等同于原始精确似然比目标；其分布层面的推导另有支持集和正密度等条件。不能把上面的无约束二次反例写成推翻MCLR，也不能把同类margin改名当成原创。第3.2–3.5节及相应假设已实际读取。

[DCR原文](https://arxiv.org/html/2603.04803v1)在冻结生成器的重建输出上施加对比监督，以协调辨别与细节。简单地在图像输出或扩散响应上附加对比项，已有直接近邻；其视觉编码器设定也不直接证明对EEG有效。

[D²-FOSA官方论文](https://openaccess.thecvf.com/content/CVPR2026/papers/Yu_D2-FOSA_Dual-Diffusion_Guided_EEG-to-Image_Reconstruction_with_Frequency-Oriented_Semantic_Alignment_CVPR_2026_paper.pdf)已有频率/阻尼的二维振荡状态块，以及EEG→视觉、视觉→EEG的双向扩散与潜空间循环约束。本次PDF直接打开返回403，只读取官方索引的摘要及第3.2–3.4节可检索段落；没有声称已逐页核对全文、实现或评价。更换Mamba、增加频谱支路、加入循环约束均不能单独作为本项目的新颖性。

[EEGRFusion官方页面](https://papers.miccai.org/miccai-2026/0338-Paper4361.html)和[作者代码说明](https://github.com/hcy1026/EEGRFusion)已有montage-aware EEG编码、Rectified Flow prior与IP-Control融合的组合。代码目录确实公开；本次只读README与文件清单，论文PDF读取超时，没有下载权重、执行setup、复现方法或接入当前队列。它表明“Flow+EEG+结构控制”也需要进一步排重，不是下一项自动准入。

[EEG foundation model benchmark第III节](https://arxiv.org/html/2601.17883v1#S3)采用跨被试及少样本协议，Things-EEG2使用三次重复及检索评价。该范围与本项目R4/R80真实图片不同，不能把表内检索分数直接当重建优势或推定换大编码器一定更好。此前本地LaBraM的嵌套读出及空间增量诊断仍保留原结论，不借新文献重启已闭合失败。

以上只使用原始论文、会议页面和作者仓库；第三方摘要没有作为方法或数值结论的依据。这不是穷尽式新颖性证明。

## 4. 完整图片结束后怎样作决定

先按原协议保留九组、八指标和十个固定比较。若标准v或T均值已解释主要改善，应将其归为基线或校准修复；若只有错误方向控制很差，还需保留优化条件差异解释。只有主方案相对direct、标准v、等尺度和公共均值具有无法由这些因素解释的实际增量，才值得沿该机制扩展。

若语义、刺激身份和结构发生分歧，逐项记录改善及代价，不把一个指标失败写成整个方法无效。下一轮的新目标必须给出明确的统计对象、参数可辨识条件和正负控制；新颖性、正常EEG推理权限及完整结果需要分别成立。当前没有增加候选、重训ordinary、接触第二卡或宣布可发表结果。
