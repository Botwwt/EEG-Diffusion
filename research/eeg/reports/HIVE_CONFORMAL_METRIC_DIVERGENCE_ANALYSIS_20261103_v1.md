# 共形条件归一化：为什么总体更像、刺激排名却下降

**本轮得到了可复核的指标分叉解释，尚无新图片效果。** 当前变换没有通过原先登记的特征门槛；这个判定保留。按用户要求，不把单项下降当作整个方向的终止理由，继续用固定模型解释原因。本轮没有追加 GPU、图片、seed 或新的 EEG 编码器训练。

## 真实拟合与留出范围

复用 sub-01 物理 R4、完整 T 的 13230 刺激／1323 概念和两个原生 OOF BrainMLP。每个编码器的排除概念块再分 A/B，拟合 A、测试 B 后反向。四个变换拟合覆盖全部 T 一次；每个测试概念同时未进入上游编码器训练和本次变换拟合。没有读取 Dfit、Dcheck、V 或 R80 来选模型。

候选将真实 EEG 输出 affine 撤销，进入其零均值球面坐标；分别计算 EEG、视觉 F 的共形重心，在中心化坐标拟合正交对应，再移到目标重心。正确／同概念错配、仅旋转、仅浓度变化、仅视觉 affine 与原生均报告。它是已有数学工具的 EEG 应用试验，不能据公式称原创。

归一化的 [Möbius 变换](https://proceedings.mlr.press/v119/rezende20a/rezende20a.pdf)已有球面流近邻；[共形重心势函数](https://arxiv.org/html/2004.03958v1#S5.SS1)也有直接来源。本实现使用有限 L-BFGS，不冒充原论文的内蕴 Newton 算法或继承其收敛保证。堆叠这类变换仍属于同一个共形群，不能把堆层数称为新增表达力。

v2 拟合及读取主体 42.477919 秒。v1 在导入 `safetensors` 时、任何真实拟合前失败；v2 仅恢复已存在且按 SHA 固定的 HIVE CPU 包路径，另存输出，并将执行上限减到 115 秒，科学公式、折划分和门槛均不变。失败保留，不能把工程间隔算进这 42 秒主体后再称整轮同样短。

## 指标分叉的精确分解

将预测和视觉目标各自单位化。某概念的十个目标为 t₁…t₁₀，平均为 μg；当前读出训练块的目标均值为 μT。正确余弦有严格恒等式：

`pᵢ·tᵢ = pᵢ·μT + pᵢ·(μg−μT) + pᵢ·(tᵢ−μg)`。

三个项依次为训练公共方向、超出训练公共方向的概念均值项、当前刺激相对同概念均值的项。这是已固定模型的描述性分解，不是因果归因或额外的推理输入。

| 共形正确配对−原生 | 平均变化 | 描述性95%区间 |
|---|---:|---|
| 训练公共方向项 | **+0.380020** | [+0.379488,+0.380599] |
| 概念均值差项 | **−0.019076** | [−0.020216,−0.017977] |
| 刺激残差项 | **−0.011890** | [−0.012407,−0.011380] |
| 三项之和，即总余弦变化 | **+0.349054** | [+0.347645,+0.350411] |

总相似度的改善来自公共方向项上升，同时概念差异项与刺激残差项下降。对九个同概念错误目标取平均，正确减错误余弦间隔又满足严格恒等式：

`marginᵢ = (10/9) × pᵢ·(tᵢ−μg)`。

实际平均间隔由 0.044987 降至 0.031776，差 −0.013211。这样就解释了为什么总余弦和 MSE 改善，刺激排名却下降：这些指标没有奖励相同的分量。不能再把“大余弦”直接解释成“更多刺激信息被恢复”。

## 下降不等于 EEG 信息已经被抹掉

对全部留出条件执行固定逆变换，方向最大误差 7.25e-16；逆变换后的原生 Top1 与 2AFC 对全部 query 均恢复，最大差为 0。原变换发生在理想 LayerNorm 球面上；不声称任意实向量或浮点字节都具备精确逆映射。

这个实测结果反对把当前排名下降全部归于不可逆信息丢失。当前被改变的是与固定视觉读出坐标的关系，以及各方向的权重。**可逆性本身也不保证读出或生成更好。** 原有“保住信息就能改善生成”的假设需要据此收窄。
