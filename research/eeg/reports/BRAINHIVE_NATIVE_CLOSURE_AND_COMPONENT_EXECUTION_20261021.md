## 从既有失败证据到这一个组件

此前全量 RealPaired/Conditional 投影器微调降低 DINO 与 SEED；模拟 q-v2 没有通过实际 EEG 输出分布保真检查。Brain-HIVE 实际 OOF 条件诊断则显示配对信息保留，但 A/P 引入很强的共同分量；仅放大 A 的输出几乎被 P 的 LayerNorm 消除。没有受控扩容证据，不能认定容量不足。

本轮只检验一个假设：在原生 EEG 条件的实际输出支持集内作有界方向修正，并用可校准的条件预测风险控制修正强度。风险表示原生 token 预测误差，**不是实测 EEG 生理信噪比**。不重新使用失真的模拟器，不增加目标、类别、caption 或真实图像特征到正常推理输入。

`BoundedConditionAdapter` 是 1024→256→1024、GELU、零初始化方向头；解除对应父模型的 LayerNorm 仿射后作零均值、切向、有界修正，再恢复原范数与仿射。最大标准化相对半径 0.25。普通适配器 525568 可训练参数；风险版本新增 256→1 头，共 525825，相差 257 参数。原生 EEG 父模型、A、P、IP K/V 和 Turbo 全部冻结。零初始化逐值恢复原输入；工程试验中新增分支产生了真实 token 和 UNet 输出变化，未把未加载分支或纯语义实验当图片实验。

CPU 已实际加载全部 132300 条两折 OOF 输入并检查真实输入的零分支。batch16 的两种分支均完成真实 UNet 反向与固定 T 图片保存，稳态约 1.11 秒/更新，峰值约 11.23 GB。工程试验只用于数值、梯度和成本，不用于 V 图片质量选优。来源见 `brainhive_bounded_component_v1.py`、`brainhive_component_generator_v1.py`、`audit/BrainHIVE_complete_component_input_loader_CPU_v16.json`、`audit/BrainHIVE_bounded_batch16_engineering_completion_v2.json`。

## 冻结的正式方案

登记配置为 `configs/BrainHIVE_bounded_main_recipe_v1.json`，其中包含代码 SHA、完整输入合同 SHA 和存储合同 SHA。

- 十被试全部 132300 个真实 OOF 训练 query，每个可训练组固定三遍，共 396900 次暴露、24807 更新。batch16，AdamW 1e-4，不扩展超参数。
- 目标为冻结原生 Turbo 的实际 epsilon MSE，加 0.1 token 角误差；风险组另加 0.1 风险 MSE。两组使用相同样本次序与独立且相同的噪声随机流。冻结权重保留原 FP16 字节，训练 BF16 autocast；推理重新加载原生 FP16 权重。
- 普通组只在 Dfit 的固定强度网格校准全局强度。风险组只在 Dfit 拟合非负仿射校准，Dcheck 一次诊断；不据 V 或官方 benchmark 调检查点或超参数。使用固定最后一次更新。
- 执行顺序为风险组件、普通适配器、原生父模型。每组完成自己的训练、全部 16600 张 V/R4 实际图片和逐 query 评价后再进入下一组。三组保持相同父链、输入权限、逐 query 噪声和 Turbo512/4步/CFG0/IP1/每query一图。
- 使用已锁定 DINO、SEED/ObjectF1、低层指标及配对统计。全部三组闭合后才作组件增量判断，不根据中途分数追加配置。
- 正向初筛要求风险组对原生及普通组的 DINO 均至少 +0.01 且配对区间下界 >0，SEED 同向且区间下界 >0，ObjectF1 不降。即使通过，也仍须固定平均门控、打乱风险、R4 EEG 干预及质量检查才能支持机制结论。后续必要控制尚未预留全部存储，不能由主三组直接宣布机制成立。

实测成本线性估计每个训练组约 7.7 GPU 小时，主三组含图片和评价约 30–36 小时。用户已取消总 GPU 时长上限；仍只用现有单卡，不购买或扩容，每项作业有有限超时及检查点。保留原 12 个候选配置及每假设两次结构修订限制，没有因换名重置。KAN、阶段路由和第二架构不插入这一轮。

## 存储与操作性失败

三组 49800 张原始无损图片的私有持久存储预测已按完整原生组最坏平均文件大小取整为 330000 字节/query，并计入评价、元数据及两个文件系统各 512 MiB 空闲缓冲；登记时总需 18457741824 字节、实际空闲 18557235200 字节。预测余量紧，运行时检查剩余生命周期，不够则保留结果后停止，不能删除历史原图凑空间。原始 EEG、学习得到的模型与历史原图未删除，C/D 不放大文件，共享公共盘不使用。

释放空间主要来自把可重算派生缓存逐字节 SHA 验证后迁到私有 RAM 并保留原路径链接；RAM **不是持久备份**，重启后须从保留的原始 EEG、模型及公开固定版本重建。当前 Turbo、CLIP 和评价模型没有被替换。无关旧 SDXL Base 公共冻结权重按固定版本留恢复入口；旧 AVDE 检查点连同优化器全部字节无损重排压缩并流式恢复 SHA 核验，没有丢弃学习权重。旧 AVDE 原 `.pth` 当前处于显式归档状态，需运行 `archive_retired_AVDE_checkpoint_losslessly_CPU_v1.py --restore-to-RAM` 后才能按原路径加载。详细回执和逐文件日志留在服务器；只同步小回执到本地。

训练图 VAE 缓存 v1 在 512 张后遭 SIGKILL，未产生完整缓存；cgroup 未记录 OOM kill，原因未定。失败源码、日志和回执保留。v2 只严格加载相同 83653863 参数原生 VAE，保持 batch4、原生图像变换、FP32 mode 与缩放规则，改为 NumPy mmap 逐块写入、SHA 与断点恢复。没有因此缩小正式数据或模型。

## 结论边界

原生 Brain-HIVE 的 EEG 配对依赖内容成立；旧投影器微调的全量图片增益被否定。当前有界风险组件仍是待检验假设。检索、token 响应、损失下降、工程图片和主三组初筛均不能各自代替完整图片增益或风险机制证据。没有容量不足的具体证据、独立 H、跨架构验证或 SOTA 结论。
