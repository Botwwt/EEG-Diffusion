# 固定 q-v2 CPU 诊断：身份难度修复，整体检查失败

日期：2026-10-19（America/Los_Angeles）。这是[文献与下一步方向报告](IDEA_NEXT_DIRECTION_LITERATURE_20261019.md)之后的实际实现与诊断，保留前一报告的历史状态。没有新增 GPU 作业、正式图片或独立验证。

## 结论

**q-v2 不能直接进入图像训练。** 它消除了 q-v1 过强的目标身份信息，条件范数、错误概念分布和能量评分改善，但固定真假条件分类器反而更容易区分模拟与真实条件。六项预定工程检查通过五项，整体失败。不能挑其中五项宣布模拟器已有效。

进一步的只读诊断发现具体结构问题：真实 ATMS 输出服从最终仿射 LayerNorm 的几何约束；当前均值加残差模拟器不保持这个约束。它提供了下一步设计依据，尚未证明该问题解释了全部分类器差距或最终图片失败。

## 新定位：输出支持集不一致

实际官方 `models/atms.py` 的 `Proj_eeg` 是1440→1024线性层、残差GELU/线性/Dropout和最终 `nn.LayerNorm(1024)`。本次读取了十个完整教师的真实检查点 `proj_eeg.2.weight/bias`，并验证其哈希。

若输出为 `c = gamma * LN(x) + beta`，则逆转可学习仿射变换后的 `z=(c-beta)/gamma` 应有近零坐标均值、接近1的坐标二阶矩（存在LayerNorm epsilon）。这与普通条件向量的L2范数对齐不同。

对原q-v2已保存模型重建同一份固定抽样，核对全部query及原范数一致；没有新拟合、重采样选择、投影修正或增加q版本。

| 绝对坐标均值的平均值 | 3.1243e−8 | 0.0023194 |
| 上述误差超过固定1e−4容差的比例 | 0% | 96.6747% |
| 二阶矩偏离1的绝对误差均值 | 3.4184e−7 | 0.0549029 |

约束失配已经证实。它使非线性判别容易在结构上成立，但没有测量其对当前MLP的归因比例，也没有做图像因果实验。T的两个OOF教师与完整教师各有自己的可学习仿射参数；除支持集外，还可能存在教师差异、条件协方差及内容关联失配。当前不能只加一次归一化就宣称全部修复。

## 对下一步创新路线的修正

1. **先保留真实配对锚。** 目前不让q-v1或q-v2替代真实EEG配对训练。Conditional相对能量/响应的积极信号仍成立，但它不足以支持部署条件已经匹配。RealPaired和Frozen完整对照继续提供接口是否有增量的证据。
2. **下一版q应显式处理教师与输出几何。** 可研究先对齐OOF/完整教师的条件坐标，再在归一化前或相应约束空间内建模内容相关残差，最后通过已知教师输出映射。先检查完整混淆分布、协方差和真假可分性，不能只让模拟范数、Top1变得相似。这里只提出待检验设计，本轮没有拟合q-v3，也不声称保持LayerNorm约束本身有新颖性。
3. **生成端区分约束单独验证，再与可信q合并。** 参考[对比重建信号论文](https://arxiv.org/html/2603.04803)，在同一加噪目标、同t和噪声下要求正确EEG比不同概念EEG得到更好的去噪支持，并保留正确配对监督及冻结参照约束。它检验生成器是否利用对象相关条件，不能只通过破坏错误条件来提高margin。[Diffusion Classifier](https://arxiv.org/html/2303.16203)说明此类差值可作生成条件诊断；本地实现仍须锁定具体损失和成本，不能称作精确likelihood。
4. **表征增强独立成基线。** [NVOL](https://arxiv.org/html/2609.02582)和[BrainHIVE](https://arxiv.org/html/2602.07495v1)提示中间视觉层及稳定生成接口，但相关组件已有先例。先证明同R4、相同权限和成本下表征基线更好，再做“表征×误差机制”的2×2比较。不要把换表征的增益算作误差机制创新。

组合顺序是：真实配对锚 → 单独检验生成端条件区分 → 几何及教师一致的q通过开发检查后再辅助训练。可靠性门控只有在能由当前EEG预测并校准时才加入；[Coherence-Aware Diffusion](https://arxiv.org/html/2405.20324)已有条件一致性先例，不能直接给它换名称。

这些都是候选机制与受控实验方向，目前没有新的图片正结果。原预算下不启动无法完成训练、全量生成、逐query评价和必要对照的新候选；继续完成已经获资源覆盖的Frozen基线。完整论文新颖性与独立增量仍待建立。
