## 2. 只使用允许T估计误差几何

对13230个T刺激、1323概念，c来自没有拟合当前概念的真实OOF ATMS；F是原始CLIP H视觉目标。定义

```text
error_i = F_i - c_i
mu = mean_T(error_i)
Sigma = mean_T[(error_i-mu)(error_i-mu)^T] = U diag(lambda) U^T
m(c) = c + mu
```

Sigma是当前EEG编码器对视觉目标的总体预测误差协方差，包含编码误差、目标表征结构和分布差异。它不是生理噪声协方差，也不是已知的逐query后验不确定性。没有假定四次EEG重复独立、没有从原始重复恢复新的物理测量信息。

真实T统计已执行：残差每坐标二阶矩0.294157；最小/最大特征值为0.0000427000/11.5257802。预定floor为平均特征值的1e-6，即2.94157e-7，本次没有特征值触发floor。这说明训练误差明显各向异性，尚不证明利用它会改善图片。

U是1024×1024的固定统计矩阵，不是免费的物理知识或可忽略的存储。所有四个新模型均使用同一个U并将输出变回原CLIP H坐标，避免把旋转本身只给主方案。均值及协方差均未读取Dcheck、V或官方目标。

## 3. 三个位置联动的参数化

以下都在U坐标中写。原前向过程仍为z=aF+b*epsilon，a²+b²=1，epsilon是人为加入、独立于训练数据的高斯噪声。对每个方向j：

```text
s_j = sqrt(a²*lambda_j + b²)
A_j = a*sqrt(lambda_j)/s_j
B_j = b/s_j
u_j = (z_j - a*m_j(c))/s_j
v_j = A_j*epsilon_j - B_j*(F_j-m_j(c))/sqrt(lambda_j)

network learns v_hat = N_theta(u, t, c_U)
D_j(z,t,c) = m_j(c) + sqrt(lambda_j)*(A_j*u_j - B_j*v_hat_j)
```

三个变化必须一起实现：输入按预测误差标准化，监督变成同坐标的v，输出再加回EEG均值并恢复原坐标。不是在条件后面随意接一个MLP，也没有替换IP/UNet/VAE或增加图像采样次数。

令r_j=(F_j-m_j)/sqrt(lambda_j)，则u_j=A_j*r_j+B_j*epsilon_j，v_j=-B_j*r_j+A_j*epsilon_j，且A_j²+B_j²=1。由二维正交旋转可直接反解F。若网络v误差为eta，干净条件误差严格为

```text
D_j-F_j = -sqrt(lambda_j)*B_j*eta_j
(D_j-F_j)² <= lambda_j*eta_j²
```

这个数值误差传播界不依赖真实EEG误差服从高斯，但它既不证明估计lambda已校准，也不保证语义、刺激身份或图片质量。普通v参数化也避免了epsilon误差除以a的放大，因此必须保留标准v强对照，不能把这一界单独当成原创定理。

若将D写成m+k(z-am)+c_out*N，还能得到经典线性高斯/EDM形式的skip和输出系数。我们不将这些公式冒称新的概率定理。

还必须明确总体最优解的边界。v空间平方误差等价于干净条件的加权误差：

```text
(v_hat_j-v_j)² = [(a²*lambda_j+b²)/(lambda_j*b²)] * (D_j-F_j)²
```

在固定z、c、t且模型容量无限时，权重为正、与待预测F无关，所以各分支的最优D仍是E[F|z,c,t]。当前设计主要改变有限网络的数值条件、各方向的优化权重及解析skip，不会仅凭此产生额外EEG信息或不同的真实后验。即使有效，也须把这种预条件贡献与新的统计学习目标区分，不能把代数重参数化描述成全新的后验理论。

## 4. 四个完整拟合与常数控制

| 分支 | 训练目标与误差尺度 | 用途 |

## 7. 近邻与贡献解释边界
