# 固定 400 图库的快速开发筛查

本方案优先复用现有模型、原图、条件、基线和 DINO 特征。它用于尽早停止没有实用信号的固定实例；不是独立确认、SOTA 评价或显著性检验。当前先完成接口和 CPU 检查，不把尚未生成的 400 条结果写成完成。

每轮先锁定候选、数据权限、完整配方及 400 条 query，再读取其输出。第一阶段保留旧的 80 条 query；另外 320 条按事前固定规则选择，不能根据候选图片挑选。**两个阶段都使用同一批 400 个目标作为图库。** 旧的 80 图库均值不与新均值拼接或直接排名。

原生 400 张图和目标特征只准备一次；之后按图片、query 身份、模型／预处理和数组文件 SHA 复用。候选先出 80 张并提取其特征；完整缓存、来源、配对噪声和身份不齐时，保留失败，不能删掉不利样本或缩小分母。扩展阶段须核验这 80 张图及其特征没有替换，再补齐其余 320 张。

CPU 核心保存每条 query 的目标余弦、400 图库 DINO2AFC／Top1、同概念十刺激 Top1／2AFC，以及 candidate−native 配对差。概念数从实际身份表读取；概念重采样固定 1000 次、seed1729，每次保留该概念的全部十条配对 query，图库始终固定。

第一阶段的固定判断为：

- DINO2AFC 差值的描述性区间上界低于 **+0.01**，停止当前实例。均值不高于 **−0.02** 且上界低于零时另标明显损害。
- 均值至少 **+0.01**、目标余弦差为正、同概念 Top1 差不为负，扩到 400；其余区间仍允许 +0.01 的不确定或指标冲突情况，也扩到 400。
- 第二阶段重新计算全部 400 条；满足相同实用方向且 DINO 差值区间下界高于零，才标记值得进入完整评价。否则停止该实例，保留“不确定”与“明显失败”的区别，不自动扫超参数。

上述区间是探索性的描述区间；重复曝光、候选选择和根据阶段结果停止／扩展不提供名义错误率控制。400 条也仍是单被试开发筛查。只把最有支持的一项固定候选送入后续十被试／完整 V 评价；若比较使用不同宿主、重复数、图库或采样成本，必须分别报告。

常见的小型解析拟合与原生四步生成轮次以 **5–10 分钟**为执行目标，远端单轮使用 **900 秒硬截止**；这不是每种新模型都能达到的保证。新接口编码、首次加载、部署、检查、传输和排错另记时间，不能把这些时间藏进“几分钟完成”的表述。截止时仅清理本轮拥有且身份核验一致的进程，保存失败与已完成产物，不自动重启或更换科学配方。

评分入口：[CPU 评分与阶段决策](../score_BrainHIVE_rapid_cached_DINO_CPU_20261027_v1.py)。`--stage 80` 读取完整 400 目标与原生缓存及候选 80 条缓存；`--stage 400` 还必须绑定原第一阶段 summary，保持缓存及旧 80 条指纹一致。该入口只读取已冻结特征，不加载 DINO 或调用 GPU。

后续将复用已完成的 full-V 配对结果，模拟不同大小／被试数的开发面板来估计这套早停规则会漏掉或误放多少历史效应。这只是对已经曝光结果的方案校准，不允许据此挑选 query、重新训练方法或宣称独立验证。

历史回放入口为 [CPU 发现与抽样回放](../replay_BrainHIVE_historical_fullV_screen_CPU_20261027_v1.py)，固定来源见[两轮已闭合结果清单](../configs/historical_screen_calibration_20261027_v1/sources.json)。第一阶段只读绑定 risk／ordinary／parent 与 O／P／PN／S 的七份旧逐 query 表；分别模拟 8／40 概念、1／3 被试，每格固定 200 个随机面板，所有概念保留十刺激，seed1729。每次抽取三被试／四十概念后，以前缀构成一被试／八概念面板，选择过程不读取效应。

旧逐 query DINO2AFC 均使用 **1660 图库**；此回放只能检查抽样 query／被试对效应方向、+0.01 分类、描述区间和 DINO 早停的影响，不能充当新 400 图库的实际校准，也不等于包含同概念 Top1 的完整多指标判据。两轮分别报告，不把 ordinary 与新 O 当同一次训练。完整 V 均值只作为历史有限样本参照，不是真实总体效应。

发现阶段同时绑定已经存在的目标与生成 DINO 特征分片及配置 SHA，供后续在 CPU 上真实重算固定 400 图库，**不重新调用 GPU 提特征**。当前实现仅读取这些分片的文件身份，不加载张量；未执行的真实图库重算不会写成完成。本地已通过 18 项评分缓存／完整 400 条数学检查，以及四项历史恒定效应／嵌套抽样／门槛边界检查；真实服务器缓存与历史回放仍以保存的实际回执为准。
