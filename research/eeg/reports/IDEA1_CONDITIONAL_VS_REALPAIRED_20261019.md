# Conditional 与 RealPaired：完整 V 图片比较

RealPaired 已完成训练、真实图片生成、全部评价及评分后的身份核验。当前结果**没有证实 Conditional 带来整体重建提升**：主指标 DINO2AFC 的小幅增加未达到预先锁定的实际增益阈值，描述性区间跨零；ObjectF1 下降，SEED 未改善。CapSim 有小幅正向信号，应与这些负向和不确定结果一起报告。

## 比较范围

两组均使用同一批十个被试、132,300 个 T 训练 query、一遍完整 query pass、8,269 次更新、seed1729、预训练初始化的原生 P 投影器（8,400,896 个可训练参数），选择最后检查点。注意力分支、生成器及本轮 ATMS 编码器冻结；这不是完整 IP 分支训练或完整公开 ATM 复现。

两组正式评价均为全部 16,600 个 V query，每个 query 一张图；相同实际 EEG 条件、目标、生成种子和初始噪声。SDXL base1.0、512、20步、CFG5、IP1，均为每 query 40 次样本级 UNet 评价，无最佳种子选择。生成时未访问目标图片或其视觉特征。RealPaired 使用真实 OOF EEG 条件；Conditional 使用经过训练数据校准的条件残差模拟，正式推理仍直接使用真实 EEG 条件。

[完整输入匹配记录](../audit/idea_interface_RealPaired_Conditional_V_matched_inputs_v1.json)逐条比较了两组全部 query 的37个字段，输出路径无复用。两组没有字节完全相同的生成图；不同 JPEG 字节本身不证明对象改善。

RealPaired 的四个 GPU 作业均 exit0，作业占用时间按监督器记录：训练8,858.283秒，T40生成55.400秒，正式生成14,624.352秒，特征提取8,043.654秒，合计约8.7727 GPU小时。编码器、OOF、校准诊断和历史失败另计入全局40小时账本；该小计不能替代全局成本。[计算账本](../audit/compute_ledger.jsonl)

截至2026-10-19 22:59:58 UTC，GPU已转到同编码器 Frozen 完整图像基线生成。Moment、Iso、Clean 的完整生命周期仍未获预算，不能写成负结果；正确/打乱/缺失 EEG 全量对照、完整多列画廊及人工画质评价仍未完成。原画廊导出估计不满足剩余空间加1GiB保留量，已记录；后续采用验证过的缩略图硬链接复用，保留历史原件。[画廊空间记录](../audit/idea_two_column_gallery_storage_preflight_v1.json)

当前否定的是“这一固定P-only单遍训练配方已证明整体图片提升”的说法；尚不能否定所有 EEG 误差适配方法。误差能量和冻结UNet响应诊断的正向结果仍成立，但没有在本次配对图片结果中转化成稳健整体收益。普通噪声对照缺失，不能确认独立机制增量；单遍训练完成不证明收敛，当前也没有哪个模块容量不足的受控证据。

下一项既定最小区分实验是完成相同编码器、相同采样种子的 Frozen 全量基线，区分“P适配是否有益”与“Conditional是否优于真实配对训练”。继续遵守总40 GPU小时，不因这次结果追加种子、扩大参数搜索或反复查看最终测试集。独立确认和可比较 SOTA 均未建立。
