## 本轮更具体的架构问题

全局条件 c 不足以描述所有局部 EEG token，但直接拼接额外 token 会改变原生图像注意力的 softmax 分母。即使局部 token 都等于 c，输出也一般会改变。因此，仅保持 memory 均值为 c，仍不足以排除全局路径被重加权的解释。

另存的锚定原型把原生图像注意力保留下来，只加入局部 EEG 相对同一 c 的响应差：

\[
R_E(q)=\operatorname{Attn}(q,K(H),V(H))-
\operatorname{Attn}(q,K(c),V(c)),
\]

\[
O_{new}=O_{native}+W_O R_E(q).
\]

两项使用同一层的真实条件 LayerNorm、Q/K/V、per-head Q/K 归一化及原生残差门；输出投影 bias 只计算一次。`H=c` 时创新归零，并显式旁路回到原生 logits／随机流／像素。EEG K/V 只由 EEG 和 c 计算，不读取真实或生成图像；正常推理只接收 EEG。没有新建可学习层，也不因此声称与原生具有相同功能容量或计算量。

当前 `63×1×200` 表示每电极一个约一秒的 patch；这不是已经验证的多时窗 EEG 层级。局部 memory 还受已有 200→1024 输出头的列空间限制，不能当成1,024个独立新增测量维度。LayerNorm 和 Q/K 归一化会引入二阶均值变化，不能把全部效应解释成协方差去噪。

[锚定原型](../EEG_anchored_attention_20261029_v1.py)已通过 **22 项 CPU 检查**：关闭／零局部信息的原生精确回退、无未来信息泄漏、原生缓存长度与清理、同生成历史的缓存 logits 一致、已有参数梯度及独立 float64 注意力差复算。使用的是作者实现的缩小随机 VAR/VQ，**尚不是完整预训练生成器的图片收益**。[完整推导、近邻与解释边界](EEG_MULTISCALE_MECHANISM_REVIEW_20261029_v1.md)
