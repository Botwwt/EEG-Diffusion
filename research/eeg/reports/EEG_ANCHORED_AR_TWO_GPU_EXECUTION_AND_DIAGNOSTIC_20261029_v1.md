## 从接口公式发现的一阶相消问题

当前包装保留原生图像注意力，仅加：

\[
R(q,H,c)=\operatorname{Attn}(q,K(H),V(H))-\operatorname{Attn}(q,K(c\mathbf1^\top),V(c\mathbf1^\top)).
\]

同一层内，令 $H_j=c+\lambda\delta_j$，$\sum_j\delta_j=0$，条件 c 固定；K/V 包含当前真实归一化、条件 affine 和每头键归一化。设这些映射在参考点可微。在 $\lambda=0$，所有参考 key/value 相同，所以权重为 $1/M$。注意力权重导数之和为零，得到：

\[
\left.\frac{\partial R}{\partial\lambda}\right|_0
=\frac1M\sum_j J_V(c)\delta_j
+\left(\sum_j\partial_\lambda w_j\right)V(c)=0.
\]

因此该固定 c 的局部方向响应从二阶起步，包含 value 映射曲率及 key/value 交叉项。若各前层也按此方式接入，确定性光滑前向中的同一零附近结论可逐层传递。**这不是“原始 EEG 无一阶信息”，也不等于真实有限幅度 memory 必然弱。** 上游 contextual EEG token已经混合多电极信息，不能把它逐一解释成未混合的电极测量。

新增数值检查使用真实作者类的缩小随机模型、float64、两种原生 key 归一化，未读取真实 EEG 或训练中的模型。12项检查全部通过：

- 一阶导最大绝对值为约 $2.53\times10^{-18}$ / $1.98\times10^{-18}$。
- 局部扰动每减半，响应范数在小幅度处约除以3.998 / 4.004，与二阶起步一致。
- 非零均值控制有非零一阶响应，排除“所有方向梯度都死掉”的解释。
- 合成的异质 key 地址保留零值回退，同时恢复非零一阶响应。这只是打破对称性的数学反例，不是已采用的 EEG 解剖位置编码或新方法收益。

## 与已有工作的关系和发表条件

EEG→多尺度AR本身已有 [AVDE](https://arxiv.org/html/2602.22555v1)，差分注意力已有 [Differential Transformer](https://arxiv.org/abs/2410.05258)，预训练注意力的差分改造也已有 [Dex](https://arxiv.org/html/2505.16333v3)。因此“不另加参数”“差分”“接入AR”都不能单独冒称原创。当前可继续检验的是：EEG全局池化后还剩哪些可解码局部差异，零回退约束会不会消掉这些差异的一阶作用，以及能否以受控结构改变换得真实刺激级图片增量。

当前10轮/micro2/AdamW1e−4/CFG1.5是另锁开发配方。AVDE正文写全局batch512、50轮，附录表6又列batch128、30轮；当前实验不能称其原论文超参数复现。最终正式比较须落实一致协议及充分拟合的强基线，而不是拿本轮单被试开发面板替代公开任务。

可发表贡献还需真实图片胜过原生与错配对照、多被试/训练seed稳定性、完整公开可比指标以及排除视觉或概念泄漏；目前均不能由训练日志或12项数学检查替代。已曝光Dcheck仅作开发，不恢复为独立确认集。
