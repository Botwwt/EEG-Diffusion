## 同一个约束问题和闭式更新

每刺激四次物理重复为 e_ir，mean4 为 ē_i。仅用相应模型允许的训练概念，估计 mean4 的重复残差协方差代理：

$$N_0=\frac1{12n}\sum_{i=1}^n\sum_{r=1}^4(e_{ir}-\bar e_i)(e_{ir}-\bar e_i)^\top,\qquad
N=0.9N_0+0.1\frac{\operatorname{tr}N_0}{4250}I.$$

1/(12n) 来自四重复的样本协方差除以4。重复内变化包含生理状态等因素，不是纯仪器噪声；收缩后的 N 更不是已知生理真值。约束只针对这个声明的度量，不保证真实噪声或后续非线性输出协方差保持。

原第一层 W0∈R^(1024×4250)。新的训练问题为

$$\min_W L_{\rm InfoNCE}\big(f(We+b),F(I)\big)
\quad\text{s.t.}\quad WNW^\top=W_0NW_0^\top.$$

令 N=LLᵀ，W0 N W0ᵀ=SSᵀ，并写作

$$\boxed{W(Q)=S Q L^{-1}},\qquad QQ^\top=I_{1024},\qquad Q_0=S^{-1}W_0L.$$

于是 W(Q) N W(Q)ᵀ=SSᵀ，且 W(Q0)=W0。输入方向可以移动，投影后的声明噪声度量保持。对 Q 的 Euclidean 梯度 G，其行 Stiefel 切空间投影为

$$G_T=G-\operatorname{sym}(GQ^\top)Q.$$

线性化损失并约束切空间步长 ||Δ||F≤r 时，闭式最优步为

$$\boxed{\Delta^*=-rG_T/\|G_T\|_F},\qquad r=0.001\sqrt{1024}.$$

有限步后使用 Cholesky 回缩：若 Q̃Q̃ᵀ=CCᵀ，则 Q_new=C⁻¹Q̃。零梯度精确不动。这个解只最小化局部线性目标，不保证回缩后或留出损失必降。

工程前向采用原第一层加精确残差的形式，Q−Q0=0 时保留原 FP32 输出。训练结束将变化折进原 W；原 bias、残差 MLP、LayerNorm 和 logit_scale 不变。模型总量仍6452224参数，每臂只训练已有4352000个第一层权重自由变量的参数化。

## 固定比较和权限

sub-01 的 full/oof0/oof1 三种原生父模型分别额外训练，每种三个臂，共9个模型：正确重复度量约束、坐标固定置换后的同谱噪声度量约束、正确度量参数化但不施加约束。全部使用相同训练概念、目标、批次、dropout随机流和固定归一化梯度步长。相同更新预算不等于回缩计算量完全相同。

每模型固定完整允许 T 十遍、batch1024、最后完整 epoch，不选最佳 epoch 或扫描步长。full 使用全部13230刺激；两种 OOF 仅使用各自相反训练概念，噪声协方差也只用其训练重复。合计810更新、793800次主 query 暴露。真实 mean4 必须逐值复现原输入，不做D08的时间池化或新输出归一化。

训练仅使用原生确定性 F 缓存的对称 batch InfoNCE，保持原 logit_scale；这与作者训练时的随机视觉教师并非完全相同。Dfit820仅做固定最终读数，不校准或选模型。正常重建仅使用当前 query 的物理 mean4；沿用原 ordinary 强度1、A/P/IP/Turbo四步。ordinary 本身在全部T训练过，不能把整个修正流程称为完全 OOF。

数值、来源和有限资源 profile 通过后，三臂均做固定80→400图片；沿用 D09 的同一400目标图库、噪声和三组强参考，预先固定 ordinary 为主参考。80条只按既有v2明确损害规则提前停止；400须主臂胜过原生／ordinary／risk及两匹配臂，不能从控制臂挑赢家。没有以 F 余弦或训练 loss 作为图片成功。
