# 基于作者代码的 EEG 生成复现与组件研究顺序

先复现同任务的公开父模型，再检验组件是否有独立图片增益。首个父模型选择 NeurIPS 2024 ATM 的公开语义生成支路。当前 ATMS 直接条件加 SDXL Base 的完整结果保留为内部机制证据；它没有完成 ATM 论文生成链路的复现。SOTA 和可迁移组件均尚未建立。

## 已有结果约束下一步

当前同编码器、同 R4、同采样配置的十被试全量比较，每组 16,600 张图：Frozen 的 DINO2AFC 为 0.758269，RealPaired 为 0.720041，Conditional 为 0.724959。两种投影器微调都未超过冻结接口。q-v2 也未通过真实与模拟条件的分布检查。这些证据要求保留原生接口，并停止把现有模拟条件当作已校验 EEG 误差分布。

新方向是**保留父模型原生条件，在有实测依据的位置加入受限的校准与路由组件**。普通残差、门控和按步调节本身都不是已证明的新颖性。贡献必须来自 EEG 条件失真或可靠性的独立校验，以及固定父模型上的完整图片增益。现在不能据此断言模型容量不足，也不能承诺该方向必定有效。

## 父模型选择

| 父模型 | 当前可用内容 | 处理顺序 |
| --- | --- | --- |
| [ATM](https://github.com/ncclab-sustech/EEG_Image_decode) | 固定作者源码、十被试匹配的公开 EEG 特征及 prior；实际图片尚未运行 | 第一对象。先匹配特征到图片，再补齐完整 EEG 到图片的复现；分别报告范围 |
| [D²-FOSA](https://openaccess.thecvf.com/content/CVPR2026/html/Yu_D2-FOSA_Dual-Diffusion_Guided_EEG-to-Image_Reconstruction_with_Frequency-Oriented_Semantic_Alignment_CVPR_2026_paper.html) | 已保存官方主文与补充 PDF；尚未定位声称随补充包发布的可执行源码 | 继续核查，不猜网络并称官方复现 |
| [DreamDiffusion](https://github.com/bbaaii/DreamDiffusion) | 已保存并审查公开数据、训练和生成入口；使用另一生成器家族 | 原始数据规格不同，THINGS 移植应单独标作改编；先处理默认图像路径问题 |
| [ENIGMA](https://github.com/Alljoined/ENIGMA) | 固定源码、网络类 CPU 检查；完整环境和图片复现未完成 | 可检验另一 EEG 映射链，但它与 ATM 都使用 Turbo/IP，不能据两者声称跨所有生成器 |

ATM 作者代码分开了检索和重建训练目标，不能把归一化检索特征直接接给要求原始 CLIP 特征的生成链。公开 prior 也不能仅凭 1024 维就与本地编码器互换。当前登记的 2,000-query 入口只复现作者特征到图片，不能代替完整 EEG 编码器训练。

DreamDiffusion 当前训练入口 `eeg_ldm.py` 的默认调用未向 `create_EEG_dataset` 传入 `imagenet_path`，后者默认 `None`；`EEGDataset` 在此分支创建随机 RGB 目标。最小 CPU 检查执行未修改的原数据类，在相同模拟 EEG 上连续读到不同目标图，已确认这一默认路径。训练复现须显式提供图像根目录并核验 stimulus 配对。这不说明作者论文使用了随机目标，也不能据此概括独立推理入口 `gen_eval_eeg.py` 的行为。其 `use_time_cond` 配置和直接条件网络也要求进一步审查；不能把“加入时间条件”当作未被研究过的空白。

IP-Adapter 已提供独立图像条件注意力，[NeuroAdapter](https://proceedings.iclr.cc/paper_files/paper/2026/hash/46cb65d30bd4931f3e71df8239c92ff0-Abstract-Conference.html)也已研究直接脑表征条件和跨去噪步骤的注意力，但后者使用 fMRI。它们是机制近邻，不能拿其异任务分数作为 EEG 基线。所谓架构通用性仍需实际验证。

## 固定执行顺序

1. **完成父模型复现。** 冻结源码版本、原始配置、数据与输入权限。ATM 先用匹配的公开特征与 prior 校验解码，再完成允许训练分区上的 EEG 编码及完整生成。每个正式阶段使用完整允许数据与全部可用被试，一个固定训练 seed 1729，每个 query 一张图；偏离作者的多图设置单独注明。
2. **定位条件瓶颈。** 真图原生条件只作工程诊断；正式正确、打乱和缺失 EEG 保持同种子与采样成本。缺失条件可能分布外，不能单凭其崩溃证明 EEG 有效。原图配对及随机标签评价自检也不能替代打乱 EEG 生成。
3. **冻结父模型，先做最简单组件。** 编码器、prior、原生投影器与生成器先保持冻结。比较原模型、普通残差适配器、带实测风险校准的残差组件。新增路径从零初始化，关闭时应精确恢复原模型；修正受限，避免整块重训破坏原生接口。
4. **再检验生成阶段路由。** 只有简化组件有可信证据后，才增加阶段依赖。按实际 scheduler 的噪声尺度或实际采样阶段定义输入；标准扩散、Turbo 与不同骨干分别核对。设置固定强度、仅质量、仅阶段、完整组件和打乱风险等匹配控制，避免一次混入多个解释不清的改动。
5. **在第二个已复现父模型上迁移。** 迁移相同机制与训练规则，使用各父模型自己的原生条件契约和权重。另一 EEG 编码器或另一 prior 的成功仅支持对应范围；跨生成器家族需额外的实际图片证据。

所有正式比较固定允许数据、信息权限、更新数、容量和采样成本，保留完整图片、逐 query 分数及失败计数。用最强匹配父模型和普通适配器判断增量，沿用 DINO 至少 +0.01、独立语义同向和预登记质量门槛；不降低阈值，不重新挑 seed，不因改名重置候选额度。

## 组件需要满足的条件

风险校准首先表示**预测条件的错误风险**，不等同于生理信噪比。当前 R4 均值不能还原四条原始 trial；不能据此构造重复间方差。若要读取基础条件之外的原始 EEG，先证明其在给定基础条件后仍有额外视觉信息，并保留 c-only 与固定 c 打乱额外 EEG 的对照。

真实折外条件必须来自完整父链：不仅 EEG 编码器，所有受目标监督训练的 prior 或映射也需排除对应概念。不能用已看过留出概念的公开 prior，拼成号称完全折外的缓存。独立校准与检查集合继续分开，沿用已锁定的训练和开发 manifest。

架构兼容需要适配向量、原生图像 token 或 cross-attention 等实际接口。共享研究机制不意味着共享同一组权重，也不意味着所有 1024 维空间可互换。组件不得增加测试目标信息、生成候选数或暗中增加去噪器调用。
