# Brain-HIVE 后续研究：定位瓶颈、有限候选与公平验证

日期：2026-10-21，America/Los_Angeles。目标是取得可复核的实际图片增益，再进入可比公开强方法评估。达到 SOTA 是研究目标，不能预设每个假设都必须成功。本文件不把新设计写成已经训练或已经提高效果。

## 1. 当前决定

保留正在执行的 risk→ordinary→parent 同协议比较，不从 risk 的单组绝对分数决定它已经失败。risk 全部 16,600 张 R4 图片和评分已闭合；ordinary 已完成固定24,807次更新并正在正式出图；parent 使用同一 EEG 编码器、A/P/IP/Turbo、查询和噪声，仍待顺序执行。当前没有匹配的组件增益结论。

后续优先检查生成器实际使用的条件误差。KAN、盲目增宽 MLP、增加采样步数、增加 EEG 通道不列为当前首选。每个改动必须对准一个经诊断支持的问题，并有能否定它的对照。

### 本轮已经执行的最小诊断

固定 sub-01 的既有 32 个 T 刺激，CPU FP32、无训练、无 UNet、未读取 D/V/官方测试条件与图片分数，实际用时约 2.78 秒。结果见 [原始回执](audit/BrainHIVE_T32_radius_CPU_actual_20261021_v1.json)。

| 量 | 原生条件 | risk 修正后 |
|---|---:|---:|
| 与正确视觉目标的 token 余弦 | 0.558946 | 0.744826 |
| 与固定异概念目标的 token 余弦 | 0.482198 | 0.686568 |
| 正确减错误余弦间隔 | 0.076748 | 0.058258 |

32/32 个样本都使用了门控后允许半径的 99% 以上；平均半径利用率 0.995552，实际标准化转角 11.021°，门控后允许角约 11.069°。这是“约束在这些样本上确实活跃”的证据，不证明解除约束能提高图片质量。

正确余弦提高时，错误目标余弦升得更多，配对间隔反而缩小约 24.1%。这支持优先检查公共分量和刺激区分监督，不能把余弦整体提高当作对象重建提高。这 32 个样本属于组件训练内，而且只有一个被试；上述间隔是平均的单个固定异概念负例差，不是全图库检索、泛化或正式图片收益，也没有用来改动正在运行的配方。

## 3. 一个需要避免的误诊

训练没有显式调用 Euler 的 `scale_model_input`，不意味着输入缩放漏了。DDPM 输入为 sqrt(alpha_bar)·x0+sqrt(1-alpha_bar)·epsilon，与 Euler 的 (x0+sigma·epsilon)/sqrt(1+sigma²) 代数等价。也没有发现 VAE 缩放重复应用或 F 条件重复经过 A。

真正已确认的差异是训练/部署的时间点与状态分布不同，以及 epsilon 误差对各时间点的 x0 误差权重不同。对同一个带噪输入，x0 误差平方等于 sigma² 乘 epsilon 误差平方；四个 sigma² 约为 213.588、16.661、2.601、0.481。这不证明当前训练目标导致图片差。作者 prior 源码也使用 DDPM 目标；需要实际诊断后才能改变。[Turbo 固定模型卡](https://huggingface.co/stabilityai/sdxl-turbo/blob/71153311d3dbb46851df1931d3ca6e939de83304/README.md)、[ADD 论文](https://arxiv.org/abs/2311.17042)。

[Brain-HIVE 论文 §4.1](https://arxiv.org/html/2602.07495v1#S4.SS1)报告默认在 SDXL-base 上预训练 Fusion Prior、在 Turbo 上四步推理。这是原方法已公开的设计，不能把骨干切换本身说成新发现的实现错误。作者发布 YAML 中模型路径仍为 TODO；本地没有公开权重逐配置的原始训练日志，论文报告与对具体权重历史的独立核验应分别表述。

## 4. 优先候选：监督原生条件的功能响应

问题：向量总余弦的提高可能主要来自公共分量，不保证生成器使用了正确刺激的差异。当前标量 gate 也不区分某个方向对哪一层、哪一个生成阶段有用。

先执行已注册的同 Q、真实原生 IP、四时间点 T32 冻结诊断。若正确视觉教师确有区分、EEG 条件仍有可利用信号，而对应功能误差明显，才进入下一训练版本。

候选训练应同时约束**接近正确教师**与**区别错误教师**，而非只让正负距离差无限增大。教师响应在宿主原生接口内计算；正常推理仍只读 EEG。四步时间点的监督及层/阶段权重必须预先固定；只有诊断支持层/阶段差异时才加入路由，不一次把所有变化叠上去。

必须控制：同参数普通分支；正确教师 MSE 控制；配对/固定打乱教师控制。使用同一数据、query 暴露、种子和生成成本；如固定参考 Q 多用了一次训练 UNet 前向，对照也要获得相同训练计算机会。推理仍为每 query 一图、4 次 UNet，不能用额外候选生成挑图。

2026-10-21 执行顺序修订（PN 尚未拟合、没有 PN 图片性能结果；已有 CPU 工程证据保留）：取消本项目此前额外提出的 T 子集训练/性能 pilot，不再创建 `functional_pilot_v1` 概念划分或据此筛选版本。用户 master 要求完整正式训练，并允许小样本工程冒烟检查；四臂各 2×16 的实际 GPU profile 仅检验梯度、数值、接口、资源与计数，不产生检查点或图片，也不能作为性能 pilot。

顺序为：事前锁定工程判据及接口 → 原三组闭合、冻结 T32 功能诊断和已有零头/关闭回放 → 四臂工程 profile、全部来源绑定与完整生命周期预算 → 各臂完整 132300 个真实 OOF-T query、三遍、24807 次正式更新，固定最后头及既有 Dfit 校准 → 固定 T32 的最终头工程图片检查 → 各臂全部 16600 张 V 图片、逐 query 评价及一次完整判读。最终头 T32 只查配对、有限值、采样调用、可解码与存储完整性；空间常数/近常数和重复等异常完整报告，不凭对象好坏选择头、重训、改强度或减少 V 输出。相同工程成本对 O/P/PN/S 一致计入台账。

本文仍不是可执行配方。拟合前须锁定 T32 功能诊断的准入判读规则、最终头 T32 的完整 query/随机流清单、校准状态、真实生成与审计入口、源 SHA、同预算对照及完整预算。当前正式 V 生成器硬限定 16600 条，不能把它或单 query 零头回放当成最终头 T32 入口；现已另行实现独立T32入口及全V artifact审计，通过CPU契约检查，实际GPU执行仍待。工程 artifact 判据不证明感知质量非劣，未定义的感知非劣界不能补填成通过。缺任一执行前置都不启动新拟合；helper 的工程通过不代替整份准入审查。

本方向是“生成器实际使用的、可由 EEG 预测的条件差异”这一研究问题，MLP/低秩头只是实现。现有响应排序代码是候选原型，不代表新增正确教师误差项、阶段路由或机制已经实现。需要检查邻近工作后才能声称创新。

## 5. 条件性备选：原生 F 空间的生成式条件 bridge

仅当真实 F 条件明显好于 EEG、且点修正的限制有实证时考虑。用真实 OOF EEG 条件学习原生 F 条件的分布，再经过冻结 A/P/IP；用刺激相关的反向约束减少与输入 EEG 无关的漂移。比较同容量单向 bridge 和确定性回归。不能把两项双向预测损失直接称作已证明的双射或精确后验。

每 query 固定一次 bridge 随机流与一次图片生成，不使用目标图选 bridge 样本。小 bridge 的额外前向次数、耗时和存储必须报告；这与扩大 UNet 采样预算分开记账。

若真实 F 条件也普遍失败，此方向暂缓，优先查先验/接口。若表现缺口指向 EEG 特征遗漏，转向有同预算对照的 EEG 表征实验；不能指望只处理现有 c 的后端组件创造已丢失的信息。

## 6. 论文对我们有何启发、不能据此声称什么

- [Brain-HIVE 原文](https://arxiv.org/html/2602.07495v1)及[官方代码](https://github.com/ssshamiii/Brain-HIVE)支持保留原生融合先验做宿主。官方重建配置每 query 10 张并平均，不是挑最好图；当前单图 R4 是另一个协议。
- [D²-FOSA 主文](https://openaccess.thecvf.com/content/CVPR2026/papers/Yu_D2-FOSA_Dual-Diffusion_Guided_EEG-to-Image_Reconstruction_with_Frequency-Oriented_Semantic_Alignment_CVPR_2026_paper.pdf)启发双向生成对齐。其 63 通道协议和当前 HIVE 17 通道并非同信息预算；未定位可执行作者代码包时，不把补充中的算法当成本仓库已具备接口。
- [UBP（CVPR 2025）](https://arxiv.org/abs/2503.04207)与[作者实现](https://github.com/HaitaoWuTJU/Uncertainty-aware-Blur-Prior)提醒我们，视觉目标细节未必都能从 EEG 恢复。单纯增加模糊或不确定性头不是新的贡献。
- [Aligning What EEG Can See（2026 预印本）](https://arxiv.org/html/2603.07077v1)与[分层生成的后续预印本](https://arxiv.org/html/2609.02582v1)提供“选择 EEG 可预测的视觉层”的可检验思路，不能把其检索准确率当作本项目图片成绩。

## 7. 阶段门槛与及时更换

| 已完成的证据 | 自动记录的决定/后续动作 |
|---|---|
| 三组尚未完成 | 保留正在运行的对照；不依据单组绝对值淘汰 |
| 风险组对两个参照均达到原 +0.01 DINO 门槛、区间下界>0，SEED 同向且下界>0，ObjectF1 不退步 | 暂留；做风险/EEG/质量机制控制，不宣布 SOTA |
| 风险组相对参照的 DINO 或 SEED 差值区间上界<0 | 当前风险配置有负面比较证据，不延长训练、不再扫它的参数；按 T 诊断更换针对性假设 |
| 没有达到预设增益，但差值区间仍跨 0 | 记为未确定/未达到实用目标，不说已经被严格否定；不为显著性重抽种子或刷 V |
| 出图/评价缺失、OOM、损坏或空间保护停止 | 运行失败，保存日志和检查点；不能判成科学失败 |

阶段判读器仅在完整比较保存后读取一次；不在训练过程中反复读取 V 分数。之后用冻结 T 诊断决定下一候选，而非针对 V 的坏图逐个修模型。延续 campaign 最多 12 个候选、每假设最多 2 次结构修订，不重置计数。

主自动判读器只裁决 risk 相对两个参照是否达到既有门槛。risk 不如 ordinary，不能推出“方向修正整体无效”：ordinary 可能优于 parent。另有 [ordinary-minus-parent CPU 队列](queue_BrainHIVE_ordinary_parent_compare_CPU_v1.py)，在三组完整闭合后一次计算全部 16,600 个 query 的独立配对差与相同的被试/概念重采样区间；当前尚未有该结果，不用均值差或两个相关区间相减代替它。

## 8. 资源与监督

20 分钟服务器巡检记录训练/生成/CPU 审计/特征提取的真实阶段、PID、增量、NaN/OOM、cgroup 内存及剩余生命周期空间。完成回执优先于最后一条 RUNNING 快照；无进展 40 分钟会告警。巡检不导入模型、不执行 GPU 前向、不读取图片得分、不杀进程或自动修改超参数。

监控覆盖当前主续跑和后续 T32；两者终止后退出，另有七天有限运行保护。记录位于服务器 `audit/bounded_20min_monitor_latest_v2.json`、`bounded_20min_monitor_v2.jsonl` 与 `bounded_20min_monitor_alerts_v2.jsonl`。这是服务器日志监控，不承诺聊天窗口每 20 分钟自动推送或让模型自动醒来重新设计科学方案。

新增训练仍需先公开：训练与必需控制的固定更新数、全量图片数、评价时间、完整存储预算和超时。当前剩余空间优先保护正在执行的三组，不因总时间上限取消就盲目再启动两套全量实验。现有单 GPU，不购买/续费/扩容，不向 C/D 放大文件。

## 9. SOTA 必须单独建立

当前 R4/V 是组件开发比较，不能用它与论文 R80/200-way 或不同指标的数字直接排名。最终须锁定官方全训练/测试、重复数、信息权限、视觉先验、指标实现和相同生成成本；允许最终全训练重拟合时，基线也须同等待遇。

固定一个训练 seed、每 query 一图是用户当前约束。公开表若用十图平均，应单列协议差异，并在所有实际运行方法间采用相同单图预算；不把作者十图表冒充本地单图配对基线。已曝光官方测试只能作为暴露 benchmark，独立确认状态仍需明确标注。

官方仓库另列的更强视觉先验若纳入，应先形成独立强基线版本，不可静默替换 H14 后把宿主变化计入组件收益。只有实际完整图片、严格比较和必要机制证据齐备，才讨论可比 SOTA；达不到时保留最好已验证系统并报告缺口。
