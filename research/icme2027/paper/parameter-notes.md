# 方法超参数的依据

| 设定 | 为什么使用 | 证据范围 |
| --- | --- | --- |
| 同物体四张照片 | 每张生成图都有三个同类干扰照。每次更新处理四组、共 16 张完整成图，在保存四步可微采样的同时形成多个对应选择。 | 固定的训练分组。比较实验保持分组和计算预算。 |
| 每组四次 EEG，波形与逐次特征按 0.72/0.28 融合 | 配对训练的每张照片有四次实测呈现。加权波形保留重复出现的信号，逐次读出保留平均时可能减弱的信号。整段融合在早期读出对照中的成图前分数优于单用加权波形。 | 保留登记的固定比例。正式 R4 消融比较两种完整读出。 |
| 256 维布局基底，校准到 80% 粗尺度 RMS | 先压缩 VAE 训练潜变量，岭回归估计较少的粗结构系数。随后用训练概念内留出的预测校准草图幅度，弱化预测布局对生成器的约束。 | 基底及幅度都从训练划分拟合。维数与 80% 为固定设置。 |
| 第一步 0.75 回混，后两步 0.11、0.02 | 四名开发被试的早期配方对照把首步强回混、次步回混改为较弱的首步回混，同时把两项末步低频修正减半。前代解码器的同类十照匹配从 18.45% 到 19.95%。 | 对照支持整套采样设置，单个系数的贡献仍待单独检验。 |
| 两种视觉相似度 0.60、0.25，布局相似度 0.15 | 对应矩阵主要由冻结的视觉特征评分，小权重补充粗布局相似度。两组消融共用这个评分定义。 | 登记的固定评分配置。 |
| Logit 倍率 15、正例权重 0.5、残差惩罚 0.05 | 15 控制匹配对相似度差的敏感程度。0.5 在有无配对项两组保持一致。0.05 约束条件离开初始化的幅度。 | 固定的优化配置。消融结论针对是否加入配对项。 |
| 128 维残差中间层、35% 范数上限 | 沿用初始化条件头的容量和改变量上限，两组训练都只更新条件残差。 | 复用的架构设置。 |

正文保留说明方法与复现实验所需的数字。早期的选型依据来自项目自己的图像布局和重复呈现实验记录。
