# 保留逐照布局的参照对照

上一组实验证实，共享训练布局降低了完整开发面板的 SSIM。新的配对目标保留每个查询自己的 EEG 布局，将固定训练集视觉均值作为参照条件。

训练时每张照片产生两幅图。当前 EEG 条件对应图的配对矩阵为 S。参照图使用相同布局、冻结生成器及逐步噪声，配对矩阵为 B。若一组 K 张照片，令 H = I − 11ᵀ/K，四张配对交叉熵改用 S − HBH。对任一配对排列，扣除的总分差只来自参照矩阵的行列交互。正配相似度和残差惩罚仍使用原规则。推理按同一个四步生成流程，每次查询输出一张图。

对照为已经完成的逐照布局组。初始权重、1,323 个训练概念、120 次更新、逐张 EEG 布局与测试种子固定。训练作业 5395752。十名被试各 200 张图的开发集成图作业 5395753 已经全部完成。

两组的逐图回执已配对核验。原照命中 86 → 95，主体命名 25 → 17，两个区间均跨零。[完整结论和全部指标](RESULTS.md)
