# 同组共享训练布局对照

这轮检验同类照片对应损失能否在共用粗构图时，仍把照片差异留在 EEG 图像条件中。

- 对照组以每张训练照片对应的 EEG 预测布局起步。
- 实验组在同组四张训练照片之间共享四份预测布局的平均值。
- 两组都沿用同一个初始化、四步生成、损失权重和 120 次优化。测试时两组均使用当前查询自己的 EEG 布局。每组在独立开发集上生成十名被试各 200 张图，共 2,000 张。
- Slurm 训练作业 5395364 的两项已完成。原成图作业 5395365 完成了被试 01、02、04，因并发重复写入同一个软链接发生冲突后，剩余任务改用只读权重入口。5395543 处理 03、05。5395568 依赖前一组完成，再处理 06–10。
- 首次训练作业 5395277 在加载旧运行环境时遇到资源函数参数不兼容。现有两组已使用修正后的启动入口完整训练。最后一次查验的状态与权重散列见 slurm-status.txt。

两组的十人生成与评分已完成。主体与原照匹配的配对区间跨零，SSIM 下降。主方法保留逐照 EEG 布局。[完整指标与区间](RESULTS.md)
